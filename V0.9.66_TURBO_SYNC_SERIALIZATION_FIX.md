## Problem Summary

**Symptom**: Nodes fail to decode BlockPackRequest messages despite using same v0.9.65-beta version

**Error Message**:
```
❌ Failed to deserialize block pack request: incompatible binary versions
Raw data: [148, 199, 191, 200, 6, 52, 49, 50, 68...]
```

**Impact**:
- Turbo Sync fails
- Falls back to HTTP sync
- **50x slower sync** (1.1 blocks/sec vs 55 blocks/sec)

---

## Root Cause Analysis

### The Data

```
First byte: 0x94 = 148 = 10010100 (binary)
           = MessagePack fixarray with 4 elements
```

**Analysis**:
- `0x94` indicates MessagePack serialization with 4-element array
- This matches `BlockPackRequest` structure (protocol_version, start_height, end_height, request_id)
- But deserialization was failing!

### Why It Failed

**MessagePack Struct Serialization has TWO modes**:

1. **Map mode** (default):
   ```
   {"protocol_version": 1, "start_height": 2435, "end_height": 3957, "request_id": "12D..."}
   ```

2. **Array mode** (compact):
   ```
   [1, 2435, 3957, "12D3..."]  ← This is what we received!
   ```

**Problem**: Code only tried Map mode, not Array mode!

```rust
// OLD CODE - Only tries map format
match rmp_serde::from_slice::<Self>(data) {
    Ok(req) => { /* Success */ }
    Err(e) => { /* Failed! */ }
}
```

## The Fix (v0.9.66-beta)

### Changes Made

**File**: `crates/q-storage/src/turbo_sync.rs`

**Location**: `decode_old_format()` function (lines 279-328)

### Before

```rust
// Only tried MessagePack map format
match rmp_serde::from_slice::<Self>(data) {
    Ok(req) => { return Ok(req); }
    Err(e) => { /* Give up */ }
}
```

### After

```rust
// ✅ Try MessagePack map format
match rmp_serde::from_slice::<Self>(data) {
    Ok(req) => {
        tracing::info!("✅ MessagePack format (map) decoded successfully!");
        req.validate_heights()?;
        return Ok(req);
    }
    Err(e) => {
        tracing::warn!("⚠️ MessagePack NEW format (map) decode failed, trying array format");
    }
}

// ✅ v0.9.66-beta: Try MessagePack array format (compact serialization)
use rmp_serde::Deserializer;
use serde::Deserialize;

let mut deserializer = Deserializer::new(&data[..]);
match Self::deserialize(&mut deserializer) {
    Ok(req) => {
        tracing::info!("✅ MessagePack format (array) decoded successfully!");
        req.validate_heights()?;
        return Ok(req);
    }
    Err(e) => {
        tracing::warn!("⚠️ MessagePack NEW format (array) decode failed, trying OLD format");
    }
}
```

## Prevention Strategy

### Long-Term Solution: Standardize on One Format

```rust
// Future: Always use Postcard (most compact and deterministic)
impl BlockPackRequest {
    pub fn to_bytes(&self) -> Vec<u8> {
        postcard::to_allocvec(self).expect("Serialization cannot fail")
    }

    pub fn from_bytes(data: &[u8]) -> Result<Self> {
        postcard::from_bytes(data)
            .context("Failed to deserialize BlockPackRequest")
    }
}

// Deprecate MessagePack/Bincode support in v0.10.0+
```

### Protocol Versioning

```rust
pub struct BlockPackRequest {
    pub protocol_version: u32,
    pub serialization_format: u8,  // ✅ NEW: Explicit format declaration
    // 0 = Postcard
    // 1 = MessagePack
    // 2 = Bincode
    pub start_height: u64,
    pub end_height: u64,
    pub request_id: String,
}
```
