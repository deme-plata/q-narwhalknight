# v0.9.2-beta: Phase 4 Network ID Fix

**Date**: November 3rd, 2025 - 22:30 CET

**Status**: 🔨 **BUILDING**

## 🎯 WHAT THIS FIX DOES

**Problem**: v0.9.1-beta was hardcoded to `testnet-phase3` network ID, causing network isolation.

**Solution**: Update all network ID references to `testnet-phase4` for Phase 4 network.

**Impact**: **All Phase 4 nodes will now communicate on the same gossipsub topics.**

## 🚀 DEPLOYMENT PLAN

### Build Status
```bash
# Build command:
timeout 600 cargo build --release --package q-api-server

# Build log:
/tmp/v0.9.2-beta-phase4-build.log

# Expected binary:
target/release/q-api-server (112 MB)
```

### Deployment Steps

#### 1. Stop Current Service
```bash
systemctl stop q-api-server
```

#### 2. Backup Old Database (CRITICAL)
```bash
# Old database is from phase3 network - incompatible with phase4
mv data-mine3 data-mine3-phase3-backup-$(date +%s)
```

**Why backup is required**:
- Old database contains blocks from `testnet-phase3` network
- Phase 4 is a clean network reset with `testnet-phase4`
- Mixing blocks causes consensus failures
- **Network reset is intentional** - fresh start for everyone

#### 3. Deploy New Binary
```bash
# Copy binary to production location
cp target/release/q-api-server /opt/orobit/shared/q-narwhalknight/q-api-server-v0.9.2-beta

# Copy to downloads folder for users
cp target/release/q-api-server /opt/orobit/shared/q-narwhalknight/gui/quantum-wallet/dist-final/downloads/q-api-server-v0.9.2-beta
cp target/release/q-api-server /opt/orobit/shared/q-narwhalknight/gui/quantum-wallet/dist-final/downloads/q-api-server-linux-x86_64

# Make executable
chmod +x /opt/orobit/shared/q-narwhalknight/gui/quantum-wallet/dist-final/downloads/q-api-server-v0.9.2-beta
chmod +x /opt/orobit/shared/q-narwhalknight/gui/quantum-wallet/dist-final/downloads/q-api-server-linux-x86_64
```

#### 4. Update Service to Use New Binary
```bash
# Option A: Update service file to point to v0.9.2-beta
sudo nano /etc/systemd/system/q-api-server.service

# Option B: Replace symlink
ln -sf /opt/orobit/shared/q-narwhalknight/target/release/q-api-server /opt/orobit/shared/q-narwhalknight/q-api-server

# Reload systemd
sudo systemctl daemon-reload
```

#### 5. Start Service
```bash
systemctl start q-api-server

# Wait for initialization
sleep 10

# Check status
systemctl status q-api-server
```

#### 6. Verify Phase 4 Network
```bash
# Check logs for phase4 topics
journalctl -u q-api-server -f | grep -i "phase4\|/qnk/testnet-phase4"

# Expected output:
# INFO q_network::unified_network_manager: 📤 Publishing block X to gossipsub topic: /qnk/testnet-phase4/blocks
```
