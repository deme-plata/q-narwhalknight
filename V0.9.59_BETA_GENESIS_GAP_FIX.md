# v0.9.59-beta: Genesis Gap Fix & HTTP Fallback Sync

## 🚨 Critical Issue Identified

### Problem: Genesis Gap on Fresh Database
**Server Alpha Status:**
- Fresh database started at height 1
- Network broadcasting live blocks at height 20,640+
- Node stuck with gap: 1 → 20,640 (20,639 missing blocks)
- Turbo sync attempted but failed to maintain continuity
- Reverted to height 1 and cannot progress

### Root Cause Analysis

**The Genesis Gap Problem:**
```
Height 1 (local) ←──── GAP (20,639 blocks) ────→ Height 20,640 (network)
         ↑                                              ↑
    Genesis block                                 Live gossipsub
    (have this)                                   (receiving these)

Missing: Heights 2-20,639 (historical blocks)
```

**Why This Happens:**
1. **Fresh database starts at genesis** (height 1)
2. **Network broadcasts only live blocks** (20,640+) via gossipsub
3. **Batch sync requests fail** because:
   - Peers don't respond to historical block requests
   - No retry mechanism for failed requests
   - Gap detection doesn't trigger HTTP fallback
4. **Turbo sync briefly worked** but couldn't maintain continuity:
   - Got some blocks (advanced to 11,844)
   - Lost continuity and reverted to last sequential height (2,244)
   - Now stuck in gap detection loop

**Current Behavior:**
```log
⚠️ [GOSSIPSUB] Gap detected at height 1 (received block 20405)
⚠️ [GOSSIPSUB] Gap detected at height 1 (received block 20406)
⚠️ [BATCH SYNC] Gap detected at height 1 - requesting missing block from peers
⚠️ [GOSSIPSUB] Gap detected at height 1 (received block 20407)
... (infinite loop, no progress)
```

### Phase 1: HTTP Fallback Sync ✅
**Purpose:** Fetch historical blocks directly from bootstrap node when P2P fails

**New Endpoint:**

```rust
pub async fn get_block_by_height(
    Path(height): Path<u64>,
    State(state): State<Arc<AppState>>,

    Ok(Json(ApiResponse::success(block)))
}

// Route: GET /api/v1/blocks/:height
```

**HTTP Gap Fill Logic:**
```rust
// crates/q-api-server/src/main.rs
async fn http_gap_fill(
    storage: Arc<QStorage>,
    start_height: u64,
    end_height: u64,
    bootstrap_url: &str,
) -> Result<u64> {
    let mut filled = 0;

    for height in start_height..=end_height {
        let url = format!("{}/api/v1/blocks/{}", bootstrap_url, height);

        match reqwest::get(&url).await {
            Ok(resp) => {
                let block: SignedBlock = resp.json().await?;

                // Validate continuity
                if block.header.height == height {
                    storage.insert_block(&block).await?;
                    filled += 1;

                    if filled % 100 == 0 {
                        info!("📥 HTTP sync: filled {} blocks (height {})", filled, height);
                    }
                }
            }
            Err(e) => {
                warn!("⚠️ HTTP sync failed at height {}: {}", height, e);
                // Retry with exponential backoff
                tokio::time::sleep(Duration::from_millis(100 * (filled % 10))).await;
            }
        }
    }

    Ok(filled)
}
```

### Phase 2: Persistent Gap Tracking ✅
**Purpose:** Remember gaps and retry until filled

**Gap Registry:**
```rust
// crates/q-storage/src/gap_registry.rs
pub struct GapRegistry {
    gaps: Arc<RwLock<BTreeMap<u64, GapInfo>>>,
    db: Arc<RocksDB>,
}

#[derive(Serialize, Deserialize, Clone)]
pub struct GapInfo {
    pub start_height: u64,
    pub end_height: u64,
    pub discovered_at: u64,
    pub retry_count: u32,
    pub last_attempt: u64,
    pub fill_strategy: GapFillStrategy,
}

#[derive(Serialize, Deserialize, Clone)]
pub enum GapFillStrategy {
    BatchSync,     // Small gaps (<100 blocks)
    TurboSync,     // Medium gaps (100-1000 blocks)
    HttpFallback,  // Large gaps (>1000 blocks) or failed retries
}

impl GapRegistry {
    pub fn register_gap(&self, start: u64, end: u64) {
        let size = end - start;
        let strategy = if size < 100 {
            GapFillStrategy::BatchSync
        } else if size < 1000 {
            GapFillStrategy::TurboSync
        } else {
            GapFillStrategy::HttpFallback
        };

        let gap = GapInfo {
            start_height: start,
            end_height: end,
            discovered_at: now(),
            retry_count: 0,
            last_attempt: 0,
            fill_strategy: strategy,
        };

        self.gaps.write().insert(start, gap);
        self.persist_gap(&gap);
    }

    pub async fn process_gaps(&self, storage: &QStorage) {
        let gaps: Vec<GapInfo> = self.gaps.read()
            .values()
            .filter(|g| g.should_retry())
            .cloned()
            .collect();

        for gap in gaps {
            match gap.fill_strategy {
                GapFillStrategy::HttpFallback => {
                    self.fill_via_http(&gap, storage).await;
                }
                GapFillStrategy::TurboSync => {
                    self.fill_via_turbo_sync(&gap, storage).await;
                }
                GapFillStrategy::BatchSync => {
                    self.fill_via_batch_sync(&gap, storage).await;
                }
            }
        }
    }
}
```

### Phase 4: Turbo Sync Continuity Fix ✅
**Purpose:** Prevent turbo sync from reverting after partial success

**Problem:** Turbo sync got to height 11,844 then reverted to 2,244

**Fix:**
```rust
// crates/q-storage/src/turbo_sync.rs
pub async fn process_block_pack(&self, pack: BlockPack) -> Result<u64> {
    let current_height = self.get_latest_height().await?;
    let pack_start = pack.blocks.first().map(|b| b.header.height).unwrap_or(0);

    // CRITICAL: Don't revert if pack is out of order
    if pack_start <= current_height {
        warn!(
            "⚠️ [TURBO SYNC] Ignoring out-of-order pack (start: {}, current: {})",
            pack_start, current_height
        );
        return Ok(0);
    }

    // Check for gap BEFORE pack
    if pack_start > current_height + 1 {
        let gap_size = pack_start - current_height - 1;
        warn!(
            "⚠️ [TURBO SYNC] Gap detected before pack: {} → {} ({} blocks missing)",
            current_height, pack_start, gap_size
        );

        // Register gap for later filling
        self.gap_registry.register_gap(current_height + 1, pack_start - 1);

        // DON'T insert these blocks yet - wait for gap to be filled
        return Ok(0);
    }

    // Process blocks sequentially
    let mut inserted = 0;
    for block in pack.blocks {
        if block.header.height == current_height + 1 {
            self.insert_block(&block).await?;
            inserted += 1;
            current_height = block.header.height;
        } else {
            warn!(
                "⚠️ [TURBO SYNC] Skipping non-sequential block (expected: {}, got: {})",
                current_height + 1, block.header.height
            );
            break;
        }
    }

    Ok(inserted)
}
```

v0.9.59-beta solves the genesis gap problem with a multi-layer approach:

1. **HTTP Fallback** - Direct bootstrap sync for large gaps
2. **Persistent Gaps** - Track and retry until filled
3. **Genesis Bootstrap** - Auto-fetch genesis on fresh database

5. **Monitoring** - Track gap fill progress
