## 🔄 **BACKGROUND METRICS REFRESH**

Added automatic metrics polling to keep the icon state updated even when the modal is closed:

```typescript
// Auto-refresh metrics every 5 seconds to update the icon glow
useEffect(() => {
  loadMetrics(); // Initial load

  const interval = setInterval(() => {
    if (!showMetrics && !isLoadingMetrics) {
      loadMetrics();
    }
  }, 5000);

  return () => clearInterval(interval);
}, [showMetrics, isLoadingMetrics]);
```

**Behavior**:
- Fetches metrics every 5 seconds in the background
- Only fetches if modal is closed (avoids duplicate requests)
- Updates `metricsData` state to trigger icon glow changes
- Cleans up interval on component unmount
