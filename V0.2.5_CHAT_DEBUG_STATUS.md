## 🔬 Potential Root Causes

Based on investigation, these are the candidates:

### Candidate #1: Multiple loadMessages Calls
**Theory**: `loadMessages()` is called multiple times in quick succession
- First call returns empty (race condition?)
- Second call returns 2 messages
- But React batching causes only one to "stick"

**Evidence Needed**: Call stack logs showing multiple invocations

### Candidate #2: Component Unmount/Remount
**Theory**: Component unmounts and remounts, resetting state
- User navigates back, component remounts with empty state
- Messages load successfully
- But then component unmounts again for some reason

**Evidence Needed**: Mount/unmount lifecycle logs

### Candidate #3: Conditional Rendering
**Theory**: Messages are loaded but not displayed due to `!currentChatId` check
- At line 797: `{!currentChatId ? "Start a New Chat" : <messages>}`
- If `currentChatId` is null when messages are loaded, they won't display

**Evidence Needed**: `currentChatId` value in state logs when messages = 2

### Candidate #4: React StrictMode Double Rendering
**Theory**: React's StrictMode causes double renders in development
- First render: empty state
- Second render: loaded state
- But second render doesn't complete properly

**Evidence Needed**: Stack traces showing double invocations
