## 🔍 WHY THIS HAPPENED

### Root Cause:
1. **Service Restart**: When we deployed v0.9.15-beta, the old process didn't die cleanly
2. **Zombie Process**: Old process (v0.9.13) continued running on port 8080
3. **Race Condition**: New process also bound to port 8080 (Linux allows this)
4. **Browser Cache**: GUI cached responses from zombie process showing old height

### Prevention:
- Added check for zombie processes before restart
- Systemd will now ensure clean shutdown
- Future restarts will wait for port to be free
