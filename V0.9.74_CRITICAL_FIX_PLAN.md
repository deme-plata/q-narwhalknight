# v0.9.74: CRITICAL FIX - Discovery Mode Too Slow

**Date**: 2025-11-09
**Priority**: 🔴 **EMERGENCY**
**Issue**: Node stuck in discovery mode - testing peers one-by-one taking 18+ hours to sync

---

## Root Cause CONFIRMED

### The Real Problem

**v0.9.73-beta peer filtering is WORKING, but discovery mode is TOO SLOW!**

**Code Location**: `crates/q-api-server/src/main.rs` lines 5043-5083

**What Happens**:
1. Node starts with ZERO compatible peers (clean state)
2. Discovery mode activated (line 5044)
3. Sends 1 test request to 1 peer (line 5062)
4. **Waits 10 seconds** for response (line 5071)
5. If no response → peer marked failed (not yet blacklisted after 1 failure)
6. Loop repeats with NEXT peer
7. After 3 failures to same peer → blacklisted
8. Continue testing peers ONE AT A TIME

**Result**: Testing 10 peers = 100 seconds minimum, only testing 1 peer at a time!

### User's Experience

- Height: 447-450 blocks (progressing slowly)
- Last batch: 9+ minutes ago
- Processing rate: 12 blocks/minute
- No compatible peers found yet
- Still in discovery mode testing peers sequentially

**This matches exactly!** 12 blocks/minute = occasional test requests succeeding

## The Fix

### Option 1: Parallel Discovery (BEST)

**Change**: Test MULTIPLE peers simultaneously in discovery mode

```rust
if top_peers.is_empty() {
    warn!("🔍 [DISCOVERY] No compatible peers found, testing 3 peers in parallel...");

    // Get 3 peers for parallel testing
    let test_peers: Vec<_> = peer_registry.iter()
        .filter(|(_, height)| *height >= network_height)
        .take(3)
        .collect();

    if !test_peers.is_empty() {
        info!("📡 [DISCOVERY] Testing {} peers simultaneously", test_peers.len());

        // Send requests to all test peers
        for (test_peer_id, _) in &test_peers {
            let chunk_size = 1000u64;
            let end_height = network_height.min(next_block_needed + chunk_size - 1);
            let block_count = (end_height - next_block_needed + 1) as usize;

            if let Err(e) = libp2p_lock.request_blocks_from_peer(*test_peer_id, next_block_needed, block_count) {
                error!("❌ [DISCOVERY] Failed to send test request: {}", e);
            } else {
                info!("✅ [DISCOVERY] Test request sent to peer {}", test_peer_id);
            }
        }

        drop(libp2p_lock);

        // Wait for ANY response (not all)
        tokio::time::sleep(std::time::Duration::from_secs(10)).await;

        let height_after_test = app_state_sync.node_status.read().await.current_height;
        if height_after_test > current_height {
            info!("✅ [DISCOVERY] At least one peer is compatible, continuing sync...");
            continue;
        }
    }

    // No responses after testing 3 peers → fall through to HTTP
    warn!("⚠️ [DISCOVERY] No compatible peers found after testing {} peers", test_peers.len());
}
```

**Benefits**:
- 3x faster discovery (3 peers tested simultaneously)
- First compatible peer unblocks sync immediately
- Falls back to HTTP if all 3 fail
