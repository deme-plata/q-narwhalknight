## Issue Description

The node was rejecting all incoming blocks with this error:
```
🚫 [BATCH SYNC] REJECTED block - wrong network_id: 'testnet-phase5' (expected: 'testnet-phase4')
```

**Root Cause**: Hardcoded `testnet-phase4` network ID in main.rs, while the NetworkId enum was correctly set to `testnet-phase5`.

## Technical Details

### Network ID Configuration

The NetworkId enum in `crates/q-types/src/lib.rs` correctly defines:
```rust
impl NetworkId {
    pub fn as_str(&self) -> &'static str {
        match self {
            NetworkId::Testnet => "testnet-phase5",  // ✅ Correct
            NetworkId::Mainnet => "mainnet",
        }
    }
}
```

The issue was that main.rs had hardcoded constants instead of using the enum method.
