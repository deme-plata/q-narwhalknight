## 🔥 USER FLOW

### **How It Works:**

1. **User Types Transaction in AI Chat:**
   ```
   "Send 50 QUG to Alice for coffee"
   ```

2. **Transaction Detection:**
   - System detects keywords: "send", "50", "QUG", "Alice"
   - Calls backend API to prepare transaction
   - Parses natural language:
     * Action: send
     * Amount: 50.0 QUG
     * Recipient: Alice
     * Memo: coffee

3. **Address Resolution:**
   - Searches address book for "Alice"
   - Finds match with 100% confidence
   - Resolves to blockchain address: `qnk8f3a2...`

4. **Security Checks:**
   - ✅ Recipient verified (in address book)
   - ✅ Balance sufficient (100 QUG available)
   - ⚠️ Large transaction warning (if >50% of balance)
   - Fraud score: 0.0 (LOW RISK)

5. **Transaction Preview Modal Shown:**
   - User reviews all details
   - Sees security analysis
   - Can confirm or cancel

6. **User Confirms:**
   - Transaction signed with quantum-resistant keys
   - Submitted to blockchain
   - Success message displayed
