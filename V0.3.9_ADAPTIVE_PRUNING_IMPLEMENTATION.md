## 🗂️ Tiered Data Retention Architecture

### Tier 0: Critical Data (Always Retained)
- **Genesis block** (block 0)
- **First 3 checkpoints** (0, 55,000, 110,000)
- **Purpose**: Network bootstrap and historical verification
- **Storage**: ~109 KB (3 × 36.4 KB)

### Tier 1: Recent Blocks (30 Days)
- **Default**: Last 1,036,800 blocks (~30 days at 2.5s block time)
- **Purpose**: Active transaction verification, re-org protection
- **Storage**: ~37.7 GB

### Tier 2: Checkpoint Blocks (Weekly)
- **Interval**: Every 55,000 blocks (~4 days)
- **Max Retained**: 52 checkpoints (~1 year)
- **Purpose**: Fast sync, state verification
- **Storage**: ~1.9 MB (52 × 36.4 KB)

### Tier 3: Historical Blocks (Pruneable)
- **All other blocks** not in Tiers 0-2
- **Can be safely pruned** without affecting network health
- **Storage Savings**: 89-95% depending on blockchain age

## 🔄 Pruning Modes

### Full Mode
```rust
PruningMode::Full
```
- **Behavior**: Keep all blockchain data (no pruning)
- **Use Case**: Archive nodes, data providers, blockchain explorers
- **Storage**: 100% (full blockchain)

### Archive Mode
```rust
PruningMode::Archive
```
- **Behavior**: Retain all data with aggressive compression
- **Use Case**: Historical research, compliance requirements
- **Storage**: 60-70% (aggressive compression)

### Light Mode
```rust
PruningMode::Light
```
- **Behavior**: Only checkpoints + recent blocks
- **Use Case**: Mobile clients, resource-constrained devices
- **Storage**: 5-11% (minimal footprint)

### Adaptive Mode (Recommended)
```rust
PruningMode::Adaptive  // Default
```
- **Behavior**: Dynamic adjustment based on disk space
- **Use Case**: General purpose nodes, auto-scaling deployments
- **Storage**: 11-15% (intelligent optimization)
- **Features**:
  - Monitors free disk space
  - Triggers aggressive pruning when disk usage > 90%
  - Automatically adjusts retention policy

## 🛡️ Security Guarantees

### 1. Network Health Preservation

**Theorem**: If ≥67% of nodes retain full data, the network can recover from any partition.

**Implementation**:
- Default adaptive mode retains 30 days (sufficient for re-org protection)
- Critical checkpoints always retained
- Genesis block never pruned

### 2. Re-org Protection

**Depth**: 24 blocks (based on empirical analysis)

**Implementation**:
- Tier 1 (Recent) includes last 1,036,800 blocks (>>24)
- All recent blocks available for chain reorganization
- Checkpoint blocks provide historical anchors

### 3. State Reconstruction

**Proposition**: Any historical state can be reconstructed from:
- Genesis block
- Checkpoint blocks
- Recent blocks

**Proof**: Checkpoints provide periodic state snapshots. Blocks between checkpoints can be requested from full nodes or re-synced from the network.

## 🚀 Usage Examples

### Basic Usage

```rust
use q_storage::pruning::{AdaptivePruningEngine, PruningConfig, PruningMode};

// Create pruning engine with default configuration
let config = PruningConfig::default();
let mut engine = AdaptivePruningEngine::new("./data", config);

// Check if block should be retained
let current_height = 110_000;
let should_keep = engine.should_retain_block(50_000, current_height)?;

// Get retention tier for a block
let tier = engine.get_retention_tier(50_000, current_height);
println!("Block 50,000 is in tier: {:?}", tier);

// Execute pruning operation
let stats = engine.execute_pruning(current_height, 110_000).await?;
println!("Pruned {} blocks, saved {} MB",
         stats.pruned_blocks,
         stats.space_saved / 1_000_000);
```

### Custom Configuration

```rust
use q_storage::pruning::{PruningConfig, PruningMode, CheckpointPolicy};

let config = PruningConfig {
    mode: PruningMode::Light,
    retain_recent_blocks_days: 7,  // Only 7 days
    min_free_disk_space: 5 * 1024 * 1024 * 1024,  // 5 GB
    checkpoint_policy: CheckpointPolicy {
        retain_genesis: true,
        checkpoint_interval: 10_000,  // More frequent checkpoints
        max_checkpoints: 100,
        reorg_protection_depth: 24,
    },
    auto_prune_interval: 1800,  // 30 minutes
    aggressive_pruning_threshold: 0.15,  // 15% free space threshold
    ..Default::default()
};

let engine = AdaptivePruningEngine::new("./data", config);
```

### Monitoring

```rust
// Get pruning statistics
if let Some(stats) = engine.get_stats() {
    println!("Last pruning:");
    println!("  - Pruned blocks: {}", stats.pruned_blocks);
    println!("  - Retained blocks: {}", stats.retained_blocks);
    println!("  - Storage efficiency: {:.1}%", stats.efficiency_percent());
    println!("  - Retention rate: {:.1}%", stats.retention_rate());
    println!("  - Duration: {} ms", stats.prune_duration_ms);
}

// Estimate storage savings
let (retained, pruned, efficiency) = engine.estimate_storage_savings(current_height)?;
println!("Estimated savings: {:.1}% ({} blocks can be pruned)",
         efficiency * 100.0, pruned);
```
