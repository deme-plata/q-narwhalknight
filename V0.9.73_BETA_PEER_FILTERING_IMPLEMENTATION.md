## Solution: Smart Peer Filtering

### 1. Peer Compatibility Tracking

**File**: `crates/q-network/src/unified_network_manager.rs`

Added `PeerCompatibility` struct to track which peers successfully support BlockPackCodec:

```rust
/// v0.9.73-beta: Peer compatibility tracking for BlockPackCodec protocol
#[derive(Debug, Clone, Default)]
pub struct PeerCompatibility {
    /// Peers that have successfully responded (PeerId → success count)
    pub successes: HashMap<PeerId, u32>,
    /// Peers that have failed to respond (PeerId → failure count)
    pub failures: HashMap<PeerId, u32>,
    /// Blacklisted peers (incompatible with BlockPackCodec)
    pub blacklist: HashSet<PeerId>,
}
```

Added to `UnifiedNetworkManager`:
```rust
pub struct UnifiedNetworkManager {
    // ... existing fields ...

    /// v0.9.73-beta: Peer compatibility tracking
    peer_compat: Arc<RwLock<PeerCompatibility>>,
}
```

### 2. Tracking Methods

**Mark Peer Success** (called on BlockPackResponse):
```rust
pub async fn mark_peer_success(&self, peer_id: PeerId) {
    let mut compat = self.peer_compat.write().await;

    // Increment success counter
    *compat.successes.entry(peer_id).or_insert(0) += 1;

    // Remove from failure list and blacklist (peer is proven working)
    compat.failures.remove(&peer_id);
    compat.blacklist.remove(&peer_id);
}
```

**Mark Peer Failure** (called on timeout/OutboundFailure):
```rust
pub async fn mark_peer_failure(&self, peer_id: PeerId) {
    let mut compat = self.peer_compat.write().await;

    // Increment failure counter
    *compat.failures.entry(peer_id).or_insert(0) += 1;
    let failure_count = compat.failures.get(&peer_id).copied().unwrap_or(0);

    // Blacklist after 3 failures
    if failure_count >= 3 {
        compat.blacklist.insert(peer_id);
        warn!("🚫 [PEER COMPAT] Peer {} BLACKLISTED (incompatible with BlockPackCodec)", peer_id);
    }
}
```

**Get Compatible Peers**:
```rust
pub async fn get_compatible_peers(&self) -> Vec<PeerId> {
    let compat = self.peer_compat.read().await;

    // Return peers with at least one success and not blacklisted
    compat.successes.keys()
        .filter(|peer_id| !compat.blacklist.contains(peer_id))
        .cloned()
        .collect()
}
```

### 4. Smart Peer Selection

**File**: `crates/q-api-server/src/main.rs` (lines 5016-5124)

**Before (v0.9.72)** - Uses ALL peers:

**After (v0.9.73)** - Only uses compatible peers:
```rust

    .filter(|(peer_id, height)| {
        compatible_peers.contains(peer_id) && *height >= network_height
    })
    .collect();
```
