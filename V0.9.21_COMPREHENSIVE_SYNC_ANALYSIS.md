### ⚠️ **ISSUE #2: Peer Height Announcements May Not Propagate**

**Location**: `crates/q-api-server/src/main.rs:3010-3035`

**Analysis**:
```rust
// Line 3010: Peer height announcement structure
struct PeerHeightAnnouncement {
    peer_id: String,
    highest_block: u64,
}

// Line 3024: Publishing to gossipsub
network_clone.send(NetworkCommand::PublishBlock {
    topic: network_id.peer_heights_topic(),  // "/qnk/testnet-phase4/peer-heights"
    block_bytes: bytes,
    block_height: height,
});
```

**Potential Problem**:
- Uses `PublishBlock` command for peer height announcements
- This command name suggests it's for blocks, not metadata
- Gossipsub might filter or handle it differently

**Expected Behavior**:
1. Node reaches height N
2. Publishes PeerHeightAnnouncement to `/qnk/testnet-phase4/peer-heights`
3. Other nodes receive announcement (lines 2687-2710)
4. Peer registry updated: `turbo_sync.register_peer(peer_id, height)`
5. TurboSync can now request blocks from that peer

**Risk Level**: MEDIUM
- If peer height announcements don't propagate, peer registry stays empty
- Empty peer registry → TurboSync skips → HTTP fallback

**Recommendation**: Monitor logs for:
```
📡 [TURBO SYNC] Peer <id> has height <N>
```
If this never appears, peer height gossipsub is broken.

### ⚠️ **ISSUE #3: TurboSync Skips If Peer Registry Empty**

**Location**: `crates/q-api-server/src/main.rs:4102-4114`

**Code**:
```rust
if peer_count == 0 {
    warn!("⚠️ [TURBO SYNC] Peer registry is EMPTY - P2P discovery issue");
    warn!("   Falling back to HTTP sync...");
}
```

**Problem**: This check is TOO STRICT

**Why It's Wrong**:
- Node might have **libp2p peer connections** (peer count > 0)
- But **peer registry** might be empty (no height announcements received)
- Result: Skips TurboSync even though peers exist

**Better Logic**:
```rust
// Check BOTH libp2p peer count AND peer registry
let libp2p_peer_count = app_state_sync.peer_count.load(Ordering::Relaxed);
let peer_registry_count = peer_registry.len();

if libp2p_peer_count == 0 {
    warn!("❌ No libp2p connections - check bootstrap peer");
} else if peer_registry_count == 0 {
    warn!("⚠️  Have {} libp2p peers but peer registry empty", libp2p_peer_count);
    warn!("   Peer height announcements not being received!");
    warn!("   Check gossipsub topic subscription");
}
```

**Risk Level**: HIGH
- Causes TurboSync to be skipped unnecessarily
- Forces HTTP fallback even when P2P could work
