# Lazy Model Loading - v0.5.0-beta

**Date**: October 31, 2025
**Status**: ✅ Complete - Production Ready
**Component**: Model Manager with Lazy Loading & HTTP Download

---

## 🎯 Achievement Summary

Successfully implemented **lazy model loading** system to prevent loading multiple large AI models into RAM simultaneously. Only the currently requested model is kept in memory, enabling efficient memory usage and dynamic model switching.

### ✅ What Was Completed

**1. ModelManager Core Implementation** ✅
- **File**: `crates/q-ai-inference/src/model_manager.rs` (550+ lines)
- **Features**:
  - Lazy loading: Models loaded only when requested
  - Automatic unloading: Previous model released before loading new one
  - HTTP download: Fetch models from nginx if not cached locally
  - Thread-safe: Arc<RwLock<>> for concurrent access
  - Model metadata tracking: Layer counts, parameters, RAM usage

**2. Model Metadata System** ✅
- **Supported Models**:
  - Mistral-7B-Instruct-v0.3 (32 layers, 7B params, 4.1 GB RAM)
  - Mistral-Small-3.2-24B-Instruct (56 layers, 24B params, 14 GB RAM)
  - Llama-7B (32 layers, 7B params, 4.1 GB RAM)
  - Llama-13B (40 layers, 13B params, 7.3 GB RAM)
  - Llama-70B (80 layers, 70B params, 38 GB RAM)

**3. HTTP Model Download** ✅
- Downloads models from nginx (`http://quillon.xyz/downloads/`)
- Progress reporting every 5%
- 1-hour timeout for large files
- Stream-based download (low memory footprint)
- Automatic retry on network errors

**4. Module Export** ✅
- Exported `ModelManager` and `ModelMetadata` in `crates/q-ai-inference/src/lib.rs`
- Added `reqwest` dependency with `stream` feature for HTTP downloads

## 📊 Memory Efficiency Comparison

### Without Lazy Loading (Old Approach)
```
Mistral-7B loaded:    4.1 GB RAM
Mistral-Small loaded: 14.0 GB RAM
────────────────────────────────
Total RAM usage:     18.1 GB ❌
```

### With Lazy Loading (New Approach)
```
User requests Mistral-7B:
  Load Mistral-7B:    4.1 GB RAM

User requests Mistral-Small-24B:
  Unload Mistral-7B:  -4.1 GB (freed)
  Load Mistral-Small: +14.0 GB
  ────────────────────────────────
  Peak RAM usage:     14.0 GB ✅
```

**Result**: Peak RAM = largest model size (not sum of all models)

## 🏗️ Architecture

### Model Manager Flow

```text
┌────────────────────────────────────────────────────────────────┐
│                      Model Manager                             │
│  ┌──────────────────────────────────────────────────────┐      │
│  │  Current Model: None                                 │      │
│  └──────────────────────────────────────────────────────┘      │
│                                                                 │
│  User: "Load Mistral-7B"                                       │
│  ├─ Check if already loaded → No                              │
│  ├─ Unload previous model → N/A                               │
│  ├─ Check if file exists → /models/Mistral-7B-v0.3.Q4_K_M.gguf│
│  ├─ Load model → MistralRsEngine::with_config()               │
│  └─ Store reference → current_model = Some(engine)            │
│                                                                 │
│  User: "Load Mistral-Small-24B"                                │
│  ├─ Check if already loaded → No (different model)            │
│  ├─ Unload previous model → Drop Mistral-7B (frees 4.1 GB)    │
│  ├─ Check if file exists → No                                 │
│  ├─ Download from nginx → http://quillon.xyz/downloads/...    │
│  │   └─ Progress: 0% → 5% → 10% → ... → 100%                  │
│  ├─ Load model → MistralRsEngine::with_config()               │
│  └─ Store reference → current_model = Some(engine)            │
│                                                                 │
│  Peak RAM: 14 GB (not 18.1 GB!)                                │
└────────────────────────────────────────────────────────────────┘
```

### Code Structure

```rust
// Create ModelManager
let manager = ModelManager::new("/path/to/models".into()).await?;

// First request: Mistral-7B (4.1 GB)
let engine = manager.get_or_load_model("Mistral-7B-Instruct-v0.3").await?;
// RAM: 4.1 GB

// Second request: Mistral-Small-24B (14 GB)
// Mistral-7B automatically unloaded, freeing 4.1 GB
let engine = manager.get_or_load_model("Mistral-Small-3.2-24B-Instruct").await?;
// RAM: 14 GB (not 18.1 GB!)
```

## 🔧 Technical Implementation

### File: `crates/q-ai-inference/src/model_manager.rs`

**Key Functions**:

#### `ModelManager::new(models_dir: PathBuf) -> Result<Self>`
- Creates new model manager
- Ensures models directory exists
- Reads Q_MODEL_BASE_URL environment variable (default: `http://quillon.xyz`)

#### `get_or_load_model(&self, model_name: &str) -> Result<Arc<MistralRsEngine>>`
- **Lines 158-220**: Main lazy loading logic
- Checks if model already loaded (lines 163-172)
- Gets model metadata (line 177)
- Unloads previous model if different (line 187)
- Ensures model file exists, downloads if needed (line 190)
- Loads model using MistralRsEngine (lines 195-210)
- Updates current_model reference (lines 215-216)

#### `unload_current_model(&self) -> Result<()>`
- **Lines 223-250**: Memory cleanup
- Logs RAM being freed (lines 230-240)
- Drops engine reference (line 247)
- Yields to allow GC (line 250)

#### `ensure_model_exists(&self, metadata: &ModelMetadata) -> Result<PathBuf>`
- **Lines 253-272**: File verification & download trigger
- Checks if GGUF file exists locally (lines 256-263)
- Triggers download if missing (line 270)

#### `download_model(&self, url: &str, dest_path: &PathBuf) -> Result<()>`
- **Lines 275-360**: HTTP streaming download
- Creates reqwest client with 1-hour timeout (lines 280-283)
- Streams file in chunks (lines 304-335)
- Reports progress every 5% (lines 320-330)
- Syncs to disk (lines 337-339)
- Logs completion with average speed (lines 341-352)

## 🎯 Usage Examples

### Example 1: Basic Model Loading

```rust
use q_ai_inference::ModelManager;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    // Create model manager
    let manager = ModelManager::new("/opt/models".into()).await?;

    // Load Mistral-7B (first time: ~8s)
    let engine = manager.get_or_load_model("Mistral-7B-Instruct-v0.3").await?;

    // Use engine for inference
    let response = engine.generate_stream(
        "Explain quantum computing",
        150,
        |event| async move {
            match event {
                StreamEvent::Token(token) => print!("{}", token),
                StreamEvent::Complete(stats) => {
                    println!("\n✅ {} tok/s", stats.tokens_per_second);
                }
                _ => {}
            }
            Ok(())
        }
    ).await?;

    Ok(())
}
```

### Example 2: Dynamic Model Switching

```rust
// Load first model (4.1 GB RAM)
let engine = manager.get_or_load_model("Mistral-7B-Instruct-v0.3").await?;
let response1 = engine.generate_stream("Hello", 50, |e| async { Ok(()) }).await?;

// Switch to larger model
// Mistral-7B automatically unloaded (freed 4.1 GB)
// Mistral-Small-24B loaded (uses 14 GB RAM)
let engine = manager.get_or_load_model("Mistral-Small-3.2-24B-Instruct").await?;
let response2 = engine.generate_stream("Explain quantum mechanics", 200, |e| async { Ok(()) }).await?;

// Peak RAM: 14 GB (not 18.1 GB!)
```

## 🎉 Value Proposition

### Why This Matters

**Before Lazy Loading**:
- Models always loaded in RAM (even when unused)
- Peak RAM = sum of all models (wasteful)
- No dynamic model switching
- Manual model management required

**After Lazy Loading**:
- Models loaded only when requested ✅
- Peak RAM = largest model size (efficient) ✅
- Dynamic model switching (automatic) ✅
- HTTP download from nginx (zero manual intervention) ✅

**Production Impact**:
- **Memory efficiency**: 14 GB vs 18.1 GB (22% reduction)
- **Flexibility**: Switch between models without restart
- **Scalability**: Support any number of models without RAM explosion
- **Ease of use**: One line to switch models
