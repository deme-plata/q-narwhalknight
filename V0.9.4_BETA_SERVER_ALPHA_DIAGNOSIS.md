**Possible Causes**:

3. **P2P Handshake**: Consensus protocol version checks may reject old versions

## 📝 LESSONS LEARNED

### Deployment Verification
- **Never assume** a service restarted with the new binary
- **Always verify** the running version matches expected version
- **Check binary timestamp** to confirm rebuild actually happened
- **Test bootstrap endpoint** after every deployment

### Version Compatibility
- **Maintain compatibility** for at least 2-3 versions back
- **Document breaking changes** in protocol/discovery format
- **Version checks** should fail gracefully with helpful error messages
- **Bootstrap discovery** should include protocol version negotiation

### Multi-Server Coordination
- **Synchronize upgrades** between bootstrap and client nodes
- **Staged rollout**: Bootstrap first, then clients
- **Backward compatibility period** during transitions
- **Monitoring** to detect version mismatches
