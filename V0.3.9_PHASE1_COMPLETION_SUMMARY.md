## Integration with Adaptive Pruning Engine

### Retention Policy Implementation

The `prune_old_blocks()` method leverages the existing `AdaptivePruningEngine` to determine which blocks to retain:

```rust
let pruning_engine = AdaptivePruningEngine::new(&self.db_path, self.pruning_config.clone());

for height in 0..=prune_up_to {
    match pruning_engine.should_retain_block(height, current_height) {
        Ok(should_retain) => {
            if !should_retain {
                // Delete block + DAG vertices + certificates
                pruned_blocks += 1;
            } else {
                retained_blocks += 1;
            }
        }
        Err(e) => {
            // Error handling - keep block to be safe
            retained_blocks += 1;
        }
    }
}
```

### Tiered Retention System

**Tier 0 - Critical** (always retained):
- Genesis block (height 0)
- Critical checkpoints (first 3 checkpoint intervals)

**Tier 1 - Recent** (retained based on config):
- Last 30 days of blocks (default: 55,000 blocks × 43,200 blocks/day)
- Configurable via `retain_recent_blocks_days`

**Tier 2 - Checkpoints** (retained):
- Every 55,000 blocks (weekly at 2-second block time)
- Configurable via `checkpoint_interval`

**Tier 3 - Historical** (pruneable):
- Blocks older than retention window
- Not checkpoints
- Deleted to reclaim space

## Cascading Deletion Architecture

### Block Deletion Flow

```
┌──────────────────────────┐
│  prune_old_blocks()      │
│  (Line 628)              │
└────────────┬─────────────┘
             │
             ▼
┌────────────────────────────────────────────────┐
│ should_retain_block(height, current_height)?   │
│ └─► AdaptivePruningEngine decision logic       │
└────────────┬───────────────────────────────────┘
             │
             ▼ (if should_retain == false)
┌────────────────────────────────────────────────┐
│ 1. Delete from CF_BLOCKS                       │
│    db.delete_cf(&cf_blocks, height.to_be_bytes())│
└────────────┬───────────────────────────────────┘
             │
             ▼
┌────────────────────────────────────────────────┐
│ 2. Delete associated DAG vertices              │
│    Prefix iteration: round_prefix = height     │
│    for each key in prefix_iterator:            │
│        db.delete_cf(&cf_dag_vertices, key)     │
└────────────┬───────────────────────────────────┘
             │
             ▼
┌────────────────────────────────────────────────┐
│ 3. Delete Bullshark certificate                │
│    db.delete_cf(&cf_bullshark_cert, height)    │
└────────────┬───────────────────────────────────┘
             │
             ▼
┌────────────────────────────────────────────────┐
│ 4. Compact database (reclaim space)            │
│    db.compact_range_cf(CF_BLOCKS)              │
│    db.compact_range_cf(CF_DAG_VERTICES)        │
│    db.compact_range_cf(CF_BULLSHARK_CERT)      │
└────────────────────────────────────────────────┘
```

## Phase 2: Background Pruning Scheduler (Next Steps)

### Implementation Guide

**Location**: `crates/q-api-server/src/main.rs` (after line 2198)

**Required Changes:**

1. **Add Pruning Scheduler Background Task**

```rust
// ========================================
// ADAPTIVE PRUNING SCHEDULER
// ========================================
{
    let app_state_pruning = app_state.clone();

    tokio::spawn(async move {
        info!("✂️  Starting adaptive pruning scheduler (every 1 hour)...");
        let mut interval = tokio::time::interval(tokio::time::Duration::from_secs(3600));

        loop {
            interval.tick().await;

            // Get current blockchain height
            let current_height = app_state_pruning.node_status.read().await.current_height;

            // Only prune if we have sufficient blockchain data
            if current_height > 100_000 {
                info!("✂️  Running adaptive pruning at height {}", current_height);

                // Access RocksDB KV store from storage engine
                // NOTE: This requires exposing get_hot_db() method on Storage wrapper
                if let Some(hot_db) = app_state_pruning.storage_engine.get_hot_db().await {
                    match hot_db.prune_old_blocks(current_height).await {
                        Ok(stats) => {
                            info!("✅ Pruning complete: {} blocks pruned, {} blocks retained",
                                  stats.pruned_blocks, stats.retained_blocks);
                            info!("💾 Storage saved: {:.2} MB ({:.1}% reduction)",
                                  stats.space_saved as f64 / 1_000_000.0,
                                  (stats.space_saved as f64 / stats.storage_before as f64) * 100.0);
                        }
                        Err(e) => {
                            warn!("⚠️  Pruning failed: {}", e);
                        }
                    }
                } else {
                    warn!("⚠️  Cannot access RocksDB for pruning");
                }
            } else {
                debug!("⏳ Skipping pruning (current height: {} < 100K minimum)", current_height);
            }
        }
    });

    info!("✅ Adaptive pruning scheduler started");
}
```
