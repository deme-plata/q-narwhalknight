## Problem Diagnosis

### Current Issue (v0.9.70-v0.9.72)

**What happens**:
1. ✅ Initial success: Gets 30+ batches from compatible peers (blocks 1-3700)
2. ❌ Then fails: Hits incompatible peers → zero responses for 6+ minutes
3. ❌ Gets stuck: Keeps sending requests that timeout
4. ❌ Never falls back: Doesn't use HTTP, just keeps failing

**Root cause**: **No peer filtering** - node requests from ALL peers including incompatible ones

## Solution: Smart Peer Filtering

### Track Peer Compatibility

**Maintain a list of "known good" peers**:
```rust
struct CompatiblePeer {
    peer_id: PeerId,
    last_success: Instant,
    success_count: u32,
    failure_count: u32,
}

// Track globally
static COMPATIBLE_PEERS: Arc<RwLock<HashMap<PeerId, CompatiblePeer>>> = ...;
```

### Response Tracking

When BlockPackCodec response arrives:
```rust
// SUCCESS - Mark peer as compatible
on_block_pack_response(peer_id, blocks) {
    let mut peers = COMPATIBLE_PEERS.write().await;
    peers.entry(peer_id).or_insert_default().success_count += 1;
    peers.entry(peer_id).last_success = Instant::now();
}

// TIMEOUT - Mark peer as incompatible
on_request_timeout(peer_id) {
    let mut peers = COMPATIBLE_PEERS.write().await;
    if let Some(peer) = peers.get_mut(&peer_id) {
        peer.failure_count += 1;
        if peer.failure_count > 3 {
            peers.remove(&peer_id); // Blacklist after 3 failures
        }
    }
}
```

### Filtered Peer Selection

**Only request from proven peers**:
```rust
// v0.9.73-beta: SMART PEER SELECTION
let compatible_peers = COMPATIBLE_PEERS.read().await;

}
```

### Phase 1: Response Tracking (v0.9.73-beta)

**File**: `crates/q-network/src/unified_network_manager.rs`

1. **Add tracking structure**:
```rust
pub struct PeerCompatibility {
    successes: HashMap<PeerId, u32>,
    failures: HashMap<PeerId, u32>,
    blacklist: HashSet<PeerId>,
}

impl UnifiedNetworkManager {
    pub fn mark_peer_success(&mut self, peer_id: PeerId) {
        *self.peer_compat.successes.entry(peer_id).or_insert(0) += 1;
        self.peer_compat.failures.remove(&peer_id);
        self.peer_compat.blacklist.remove(&peer_id);
    }

    pub fn mark_peer_failure(&mut self, peer_id: PeerId) {
        *self.peer_compat.failures.entry(peer_id).or_insert(0) += 1;
        if self.peer_compat.failures[&peer_id] > 3 {
            self.peer_compat.blacklist.insert(peer_id);
        }
    }

    pub fn get_compatible_peers(&self) -> Vec<PeerId> {
        self.peer_compat.successes.keys()
            .filter(|p| !self.peer_compat.blacklist.contains(p))
            .cloned()
            .collect()
    }
}
```
