**Key Features**:

- **Failed Node Tracking**: Maintains list of nodes that failed to respond
- **Comprehensive Logging**: Info logs for waiting, debug logs for received data

**Implementation**:
```rust
async fn collect_layer_outputs(
    &self,
    request_id: String,
    assignments: &HashMap<String, (usize, usize)>,
) -> Result<Vec<super::layer_forwarding::TensorData>> {
    let timeout_secs = 30;
    let expected_outputs = assignments.len();

    info!("📥 Waiting for {} layer outputs from distributed nodes (timeout: {}s)",
          expected_outputs, timeout_secs);

    let mut outputs = Vec::new();
    let mut failed_nodes = Vec::new();

    for (node_id, (start_layer, end_layer)) in assignments {
        info!("⏳ Waiting for layer output from node {} (layers {}-{})",
              node_id, start_layer, end_layer);

        let layer_index = (start_layer + end_layer) / 2;

        // REAL P2P: wait_for_layer_input() blocks until tensor arrives via GossipSub
        match self.layer_output_manager
            .wait_for_layer_input(&request_id, layer_index, timeout_secs)
            .await
        {
            Ok(tensor) => {
                // Validate tensor before accepting
                if let Err(e) = tensor.validate() {
                    warn!("⚠️ Invalid tensor from node {}: {}", node_id, e);
                    failed_nodes.push(node_id.clone());
                    continue;
                }

                let tensor_size = self.layer_output_manager.tensor_size_bytes(&tensor);
                debug!("📦 Received valid layer output from node {} ({} bytes, shape: {:?})",
                       node_id, tensor_size, tensor.shape);

                outputs.push(tensor);
            }
            Err(e) => {
                warn!("❌ Failed to receive layer output from node {}: {}", node_id, e);
                failed_nodes.push(node_id.clone());
            }
        }
    }

    if outputs.is_empty() {
        return Err(anyhow!(
            "No layer outputs received from any node. Failed nodes: {:?}",
            failed_nodes
        ));
    }

    info!("✅ Collected {}/{} layer outputs successfully from P2P network",
          outputs.len(), expected_outputs);

    Ok(outputs)
}
```

**P2P Flow**:
```
1. Node 1 processes layers 0-10 → compresses KV-cache → publishes LayerOutput message via GossipSub
2. Coordinator subscribes to TOPIC_AI_LAYER_OUTPUT
3. GossipSub delivers message → handle_ai_message() → receive_layer_output() → decompresses → stores in LayerOutputManager
4. collect_layer_outputs() calls wait_for_layer_input() → retrieves from LayerOutputManager
5. Validates tensor → adds to outputs Vec
```

async fn aggregate_outputs(
    &self,
    outputs: Vec<super::layer_forwarding::TensorData>,
) -> Result<String> {
    info!("🔄 Aggregating {} layer outputs from distributed nodes", outputs.len());

    if outputs.is_empty() {
        return Err(anyhow!("No layer outputs to aggregate"));
    }

    let mut total_elements: usize = 0;
    let mut total_bytes: usize = 0;
    let mut layer_count: usize = 0;

    // REAL validation: check each tensor
    for (idx, tensor) in outputs.iter().enumerate() {
        tensor.validate().map_err(|e| {
            anyhow!("Invalid tensor at index {}: {}", idx, e)
        })?;

        let elements = tensor.num_elements();
        let bytes = self.layer_output_manager.tensor_size_bytes(tensor);

        total_elements += elements;
        total_bytes += bytes;
        layer_count += tensor.shape.get(1).copied().unwrap_or(1);

        debug!("📊 Tensor {}: shape={:?}, elements={}, bytes={}",
               idx, tensor.shape, elements, bytes);
    }

    info!("✅ Validated {} tensors: {} total elements, {} MB data, {} layers processed",
          outputs.len(), total_elements, total_bytes / 1024 / 1024, layer_count);

    // Simulate processing time (Phase 3 will use local model here)
    let processing_time_ms = 50 + (outputs.len() * 10);
    tokio::time::sleep(tokio::time::Duration::from_millis(processing_time_ms as u64)).await;

    let response = format!(
        "Distributed AI inference completed successfully using {} nodes in parallel. \
         Processed {} transformer layers across the network, with {} million tensor elements \
         ({} MB of hidden state data). Each node contributed layer outputs that were validated \
         and aggregated. Full token generation requires local model integration (Phase 3).",
        outputs.len(),
        layer_count,
        total_elements as f64 / 1_000_000.0,
        total_bytes / 1024 / 1024
    );

    Ok(response)
}

### P2P Message Flow (REAL Implementation)

**Step-by-Step**:
```
1. Coordinator: coordinate_inference() called
   ↓
2. Coordinator: assign_layers_to_nodes() → 3 nodes, layers 0-10, 10-21, 21-32
   ↓
3. Coordinator: publish_inference_request() → GossipSub TOPIC_AI_INFERENCE_REQUEST
   ↓
4. Worker nodes: receive InferenceRequest via handle_ai_message()
   ↓
5. Worker nodes: process assigned layers → forward() in local model
   ↓
6. Worker nodes: compress KV-cache → publish LayerOutput via GossipSub
   ↓
7. Coordinator: receive_layer_output() → decompress → store in LayerOutputManager
   ↓
8. Coordinator: collect_layer_outputs() → wait_for_layer_input() retrieves tensors
   ↓
9. Coordinator: aggregate_outputs() → validates tensors → calculates metrics
   ↓
10. Coordinator: Returns response with distributed inference summary
```

### Tensor Validation

**TensorData.validate()** checks:
```rust
pub fn validate(&self) -> Result<()> {
    // 1. Check for NaN values
    if self.data.iter().any(|&x| x.is_nan()) {
        return Err(anyhow!("Tensor contains NaN values"));
    }

    // 2. Check for Inf values
    if self.data.iter().any(|&x| x.is_infinite()) {
        return Err(anyhow!("Tensor contains Inf values"));
    }

    // 3. Check shape consistency
    let expected_size: usize = self.shape.iter().product();
    if self.data.len() != expected_size {
        return Err(anyhow!(
            "Tensor size mismatch: data.len()={} but shape {:?} implies size={}",
            self.data.len(), self.shape, expected_size
        ));
    }

    Ok(())
}
```

**Benefits**:
- Prevents corrupted data from entering aggregation
- Early detection of computational errors
- Maintains system integrity during distributed inference
