## 🎯 THE PROBLEM: New Nodes Couldn't Sync

New users trying to join the Q-NarwhalKnight network at height 0 got stuck in a circular dependency:

1. Node starts at height 0
2. Skips announcing itself to network
3. Never receives peer height updates
4. Sync never triggers
5. **STUCK FOREVER** ❌

This prevented network growth and made onboarding impossible.
