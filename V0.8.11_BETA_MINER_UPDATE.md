## 🎯 Issue Summary

### User Report

**Problem**: Local miner showing 0.00 MH/s despite being "connected"
- Miner binary: v0.3.9-beta (October 31, 2024)
- Node binary: v0.8.11-beta (November 3, 2025)
- **Gap**: ~1 year of protocol changes

### Root Cause

**Binary Version Mismatch**:
```bash
$ ls -lh /opt/orobit/shared/q-narwhalknight/target/release/q-miner
-rwxr-xr-x 2 root root 14M Oct 31 00:47 q-miner  # OLD (v0.3.9-beta)
```

**Protocol Changes** (v0.3.9 → v0.8.11):
- BlockHeader structure changed (producer_id field added)
- Network ID changed (testnet-phase2 → testnet-phase3)
- Mining API may have evolved
- Difficulty calculation updated

**Result**: Old miner doesn't understand new protocol → 0 hash rate

## 🔧 Troubleshooting

### Issue: "Connection refused"

**Symptom**: Miner can't connect to node
```
Error: Connection refused (http://185.182.185.227:8080)
```

**Solution**: Check node is running
```bash
curl http://185.182.185.227:8080/api/node/info
```

If node responds, check firewall settings.

### Issue: "Invalid wallet address"

**Symptom**: Miner rejects wallet address
```
Error: Invalid wallet address format
```

**Solution**: Wallet address must start with "qnk" and be 19 characters total
```
Format: qnk + 16 hex characters
Example: qnk1e0227f4cd20e
```

### Issue: "Still 0 MH/s"

**Symptom**: New miner shows 0 MH/s

**Checklist**:
1. ✅ Downloaded v0.8.11-beta (not v0.3.9-beta)?
   ```bash
   ls -lh q-miner-v0.8.11-beta  # Should show Nov 3 20:01
   ```

2. ✅ Made binary executable?
   ```bash
   chmod +x q-miner-v0.8.11-beta
   ```

3. ✅ Running correct binary?
   ```bash
   ./q-miner-v0.8.11-beta  # NOT ./q-miner-v0.3.9-beta
   ```

4. ✅ Node is reachable?
   ```bash
   curl http://185.182.185.227:8080/api/node/info
   ```

If all checks pass and still 0 MH/s, check miner logs for errors.
