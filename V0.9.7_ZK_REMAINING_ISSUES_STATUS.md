## ⏳ PENDING: Issue #8 - Optimize Rate Limiter

### Current Issue
**Location**: `crates/q-storage/src/zk_block_request_auth.rs:114-139`

**Problem**: Write lock held for entire function duration, blocks concurrent rate limit checks.

### Proposed Solution: Token Bucket Algorithm

**Benefits**:
- Lock-free implementation using atomics
- Allows burst traffic within limits
- More performant than sliding window
- Industry-standard rate limiting

**Implementation Plan**:
```rust
use std::sync::atomic::{AtomicU64, Ordering};

pub struct TokenBucketRateLimiter {
    /// Token bucket: peer_id -> (tokens, last_refill_time)
    buckets: Arc<RwLock<HashMap<PeerId, (AtomicU64, AtomicU64)>>>,

    /// Maximum tokens per bucket (burst capacity)
    max_tokens: u64,

    /// Token refill rate (tokens per second)
    refill_rate: u64,
}

impl TokenBucketRateLimiter {
    pub async fn check_rate_limit(&self, peer_id: &PeerId) -> Result<bool> {
        let now = Instant::now().as_secs();

        // Try read-only fast path first
        {
            let buckets = self.buckets.read().await;
            if let Some((tokens, last_refill)) = buckets.get(peer_id) {
                let current_tokens = tokens.load(Ordering::Relaxed);

                // Fast path: consume token without refill
                if current_tokens > 0 {
                    if tokens.compare_exchange(
                        current_tokens,
                        current_tokens - 1,
                        Ordering::SeqCst,
                        Ordering::Relaxed
                    ).is_ok() {
                        return Ok(true); // Token consumed, request allowed
                    }
                }
            }
        }

        // Slow path: need refill or new bucket
        let mut buckets = self.buckets.write().await;
        let (tokens, last_refill) = buckets
            .entry(*peer_id)
            .or_insert((AtomicU64::new(self.max_tokens), AtomicU64::new(now)));

        // Refill tokens based on time elapsed
        let last = last_refill.load(Ordering::Relaxed);
        let elapsed = now - last;
        let new_tokens = std::cmp::min(
            tokens.load(Ordering::Relaxed) + (elapsed * self.refill_rate),
            self.max_tokens
        );

        tokens.store(new_tokens, Ordering::Relaxed);
        last_refill.store(now, Ordering::Relaxed);

        // Try consume token
        let current = tokens.load(Ordering::Relaxed);
        if current > 0 {
            tokens.store(current - 1, Ordering::Relaxed);
            Ok(true)
        } else {
            warn!("⚠️ [RATE LIMIT] Peer {} exhausted tokens", peer_id);
            Ok(false)
        }
    }
}
```
