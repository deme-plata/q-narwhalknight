## 🔍 TROUBLESHOOTING

### Problem: Service Won't Start

**Error**: `Failed to deserialize QBlock` or `tag for enum is not valid`

**Solution**: You forgot to delete the old database!

```bash
# Delete old database:
rm -rf data-mine3

# Restart service:
sudo systemctl restart q-api-server
```

### Problem: Zero Peers After 10 Minutes

**Check Network ID**:
```bash
journalctl -u q-api-server | grep "testnet-phase"
```

**Expected**: `testnet-phase4`
**If you see**: `testnet-phase3` → You're running the wrong version!

**Solution**: Re-download v0.9.2-beta and ensure you're running the new binary.

### Problem: "Can't Sync to Latest Block"

**Check Current Height**:
```bash
curl -s http://localhost:8080/api/node/info | jq '{height, peer_count, is_syncing}'
```

**If `peer_count: 0`**: Network isolation - verify you're on testnet-phase4

**If `is_syncing: false` and height stuck**: Restart node to trigger sync

```bash
sudo systemctl restart q-api-server
```

### Problem: Height Keeps Resetting

**This should NOT happen anymore!** If it does:

1. Check for pruning messages in logs:
```bash
journalctl -u q-api-server | grep -i "prun\|delet"
```

2. Verify you're running v0.9.2-beta:
```bash
./q-api-server-v0.9.2-beta --version || strings q-api-server-v0.9.2-beta | grep "testnet-phase4"
```

3. Report the issue with full logs
