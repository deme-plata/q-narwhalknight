## 🚨 ROOT CAUSE CONFIRMED

### Problem: Storage Injection Deadlock

**Server Alpha** Phase 3 initialization logs show:
```
❌ Phase 3a: Timeout acquiring libp2p manager lock - skipping storage injection
❌ Phase 3b: Timeout acquiring libp2p manager lock - skipping block sync channel
```

**What this means:**
1. libp2p event loop spawns at line 999 and immediately calls `manager.lock().await`
2. Event loop holds the lock for the entire duration of `run().await` (which runs forever)
3. Phase 3 initialization tries to lock the manager at lines 1276 and 1290
4. Timeout after 5 seconds because event loop won't release the lock
5. Storage and block sync channel are NEVER set
6. BlockPackCodec handler can't respond to requests (no storage access)

---

## 📊 Impact

**Server Alpha (sync node):**
- ✅ Event loop IS running
- ✅ Peers ARE connected
- ✅ BlockPackCodec requests from Server Beta arrive at handler
- ❌ Handler has `storage = None`, can't fetch blocks to respond
- ❌ All BlockPackCodec requests time out after 90 seconds
- ✅ HTTP fallback works (doesn't need injected storage reference)

**Result**: Stuck at ~40 blocks/second (HTTP) instead of 1000+ blocks/second (P2P TURBO SYNC)

---

## 🔧 THE FIX

### Solution: Set Storage BEFORE Spawning Event Loop

**Current broken order** (`crates/q-api-server/src/main.rs`):
```rust
// Line 910-999: Create network manager
let libp2p_manager = UnifiedNetworkManager::new(network_config).await?;

// Line 996-1005: IMMEDIATELY spawn event loop (locks manager forever)
let manager_arc = Arc::new(Mutex::new(manager));
tokio::spawn(async move {
    let mut nm = manager_clone.lock().await; // ← Locks manager
    nm.run().await; // ← Never returns, holds lock forever
});

// Line 1270-1299: Try to set storage (DEADLOCK!)
manager.lock().await.set_storage(...); // ← Times out after 5s
```

**Fixed order:**
```rust
// 1. Create network manager (don't wrap in Arc yet)
let mut libp2p_manager = UnifiedNetworkManager::new(network_config).await?;

// 2. Set storage BEFORE wrapping (no lock needed)
libp2p_manager.set_storage(storage_engine.clone());
info!("✅ Storage engine linked to network manager");

// 3. Set block sync channel BEFORE wrapping
let (block_sync_tx, block_sync_rx) = mpsc::unbounded_channel();
libp2p_manager.set_block_sync_channel(block_sync_tx);
info!("✅ Block sync forwarding channel established");

// 4. NOW wrap in Arc and spawn event loop
let manager_arc = Arc::new(Mutex::new(libp2p_manager));
tokio::spawn(async move {
    let mut nm = manager_clone.lock().await;
    nm.run().await;
});
```

## 📝 Implementation

### File: `crates/q-api-server/src/main.rs`

**Change 1:** Move storage/channel setup to initialization phase (lines 910-1015)

**Before** (lines 996-1008):
```rust
// Start network event loop
let manager_arc = Arc::new(tokio::sync::Mutex::new(manager));
let manager_clone = manager_arc.clone();

tokio::spawn(async move {
    info!("🔄 Starting libp2p network event loop...");
    let mut nm = manager_clone.lock().await;
    if let Err(e) = nm.run().await {
        error!("❌ Network manager event loop terminated: {}", e);
    }
});

info!("✅ libp2p network fully operational");
Some((manager_arc, gossipsub_rx, gossipsub_tx_clone, command_tx, peer_count_atomic, cached_peer_info))
```

**After:**
```rust
// ✅ v0.9.75-beta: Set storage BEFORE spawning event loop to prevent deadlock
// CRITICAL: Storage must be set while manager is still owned (not Arc-wrapped)
// If we spawn the event loop first, it locks the manager forever and Phase 3
// storage injection times out, breaking BlockPackCodec responses.

// Note: We don't have storage_engine yet at this point in initialization.
// We'll return the manager and set storage in Phase 3, but BEFORE spawning the event loop.

info!("✅ libp2p manager initialized (storage will be set in Phase 3)");
Some((manager, gossipsub_rx, gossipsub_tx_clone, command_tx, peer_count_atomic, cached_peer_info))
```

**Change 2:** Update Phase 3 to spawn event loop AFTER setting storage (lines 1270-1340)

**Before** (lines 1270-1299):
```rust
if let Some(ref libp2p_manager) = state.libp2p_discovery {
    info!("🔄 Setting up Phase 3 libp2p block synchronization...");

    // Phase 3a: Inject storage (WITH TIMEOUT - DEADLOCK!)
    {
        match tokio::time::timeout(Duration::from_secs(5), libp2p_manager.lock()).await {
            Ok(mut manager) => {
                manager.set_storage(state.storage_engine.clone());
                info!("✅ Phase 3a: Storage engine linked");
            }
            Err(_) => {
                warn!("⚠️  Phase 3a: Timeout acquiring lock - skipping storage");
            }
        }
    }

    // Phase 3b: Set block sync channel (WITH TIMEOUT - DEADLOCK!)
    let (block_sync_tx, mut block_sync_rx) = mpsc::unbounded_channel();
    {
        match tokio::time::timeout(Duration::from_secs(5), libp2p_manager.lock()).await {
            Ok(mut manager) => {
                manager.set_block_sync_channel(block_sync_tx);
                info!("✅ Phase 3b: Block sync channel established");
            }
            Err(_) => {
                warn!("⚠️  Phase 3b: Timeout acquiring lock - skipping channel");
            }
        }
    }
}
```

**After:**
```rust
// ✅ v0.9.75-beta: Fix BlockPackCodec deadlock by setting storage BEFORE spawning event loop
if let Some(mut libp2p_manager) = state.libp2p_discovery {
    info!("🔄 Setting up Phase 3 libp2p block synchronization...");

    // Phase 3a: Inject storage (NO LOCK NEEDED - manager still owned)
    libp2p_manager.set_storage(state.storage_engine.clone());
    info!("✅ Phase 3a: Storage engine linked to network manager");

    // Phase 3b: Set block sync channel (NO LOCK NEEDED)
    let (block_sync_tx, mut block_sync_rx) = mpsc::unbounded_channel();
    libp2p_manager.set_block_sync_channel(block_sync_tx);
    info!("✅ Phase 3b: Block sync forwarding channel established");

    // Phase 3c: NOW wrap in Arc and spawn event loop
    let manager_arc = Arc::new(tokio::sync::Mutex::new(libp2p_manager));
    let manager_clone = manager_arc.clone();

    tokio::spawn(async move {
        info!("🔄 Starting libp2p network event loop...");
        let mut nm = manager_clone.lock().await;
        if let Err(e) = nm.run().await {
            error!("❌ Network manager event loop terminated: {}", e);
        }
    });

    info!("✅ libp2p network fully operational with storage and block sync");

    // Update state with Arc-wrapped manager
    state.libp2p_discovery = Some(manager_arc);

    // Continue with block sync receiver processing...
}
```
