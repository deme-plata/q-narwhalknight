## 📊 PERFORMANCE IMPACT

### Signature Overhead:

```
Operation                   Time      Size Overhead
──────────────────────────────────────────────────
Dilithium5 signing          ~2ms      +2420 bytes
Dilithium5 verification     ~3ms      N/A
Merkle root computation     ~5ms      +32 bytes
Timestamp check             ~0.1ms    +8 bytes
Peer trust update           ~0.1ms    N/A
──────────────────────────────────────────────────
TOTAL PER PACK              ~10ms     +2.4 KB
```

**Impact Analysis**:
- **5000-block pack**: 10ms overhead on 300ms total = 3.3% slower
- **Gossipsub message size**: +2.4 KB = +0.4% size increase
- **Security benefit**: Byzantine fault tolerance, prevents malicious block injection
- **Trade-off**: 3% performance cost for quantum-resistant cryptographic security

### Bandwidth Analysis:

```
Current BlockPack (5000 blocks):
- Compressed data: ~600 KB (zstd level 3)
- Total message: ~600 KB

SignedBlockPack (5000 blocks):
- Blocks (uncompressed): ~2 MB (400 bytes/block average)
- Merkle root: 32 bytes
- Dilithium5 signature: 2420 bytes
- Public key: 1312 bytes
- Timestamp: 8 bytes
- Peer ID: ~50 bytes
- Total: ~2 MB + 3.8 KB = **2003 KB**

**CRITICAL ISSUE**: SignedBlockPack sends UNCOMPRESSED blocks!
```

**Solution**: Hybrid approach needed:
1. Compress blocks with zstd BEFORE signing
2. Sign the compressed data + merkle root
3. Verify signature, then decompress

```rust
pub struct SignedBlockPack {
    /// Compressed blocks (zstd level 3)
    pub compressed_blocks: Vec<u8>,

    /// Original block count (for validation)
    pub block_count: usize,

    /// Start and end heights
    pub start_height: u64,
    pub end_height: u64,

    /// Merkle root of UNCOMPRESSED block hashes
    pub merkle_root: [u8; 32],

    /// AEGIS-QL signature over (compressed_blocks || merkle_root || timestamp)
    pub aegis_signature: q_aegis_ql::Signature,

    /// Sender's public key
    pub peer_public_key: q_aegis_ql::PublicKey,

    /// Timestamp
    pub timestamp: i64,

    /// Peer ID
    pub peer_id: String,
}
```

**Implementation**:
```rust
pub async fn create_signed_block_pack_compressed(
    &self,
    blocks: Vec<QBlock>,
    peer_id: String,
) -> Result<SignedBlockPack> {
    // 1. Compute merkle root of UNCOMPRESSED blocks
    let block_hashes: Vec<[u8; 32]> = blocks.iter()
        .map(|b| b.calculate_hash())
        .collect();
    let merkle_root = compute_merkle_root(&block_hashes);

    // 2. Compress blocks
    let serialized = postcard::to_allocvec(&blocks)?;
    let compressed = zstd::bulk::compress(&serialized, 3)?;

    info!("🗜️  [AEGIS-QL] Compressed {} blocks: {} → {} bytes ({:.1}% compression)",
          blocks.len(),
          serialized.len(),
          compressed.len(),
          (1.0 - compressed.len() as f64 / serialized.len() as f64) * 100.0);

    // 3. Sign compressed data + merkle root
    let timestamp = chrono::Utc::now().timestamp();
    let mut message = Vec::new();
    message.extend_from_slice(&compressed);  // Sign compressed data
    message.extend_from_slice(&merkle_root);
    message.extend_from_slice(&timestamp.to_le_bytes());
    message.extend_from_slice(peer_id.as_bytes());

    let mut aegis = self.aegis.lock().await;
    let secret_key = self.aegis_secret_key.read().await;
    let signature = aegis.sign(&message, &*secret_key)?;

    Ok(SignedBlockPack {
        compressed_blocks: compressed,
        block_count: blocks.len(),
        start_height: blocks.first().map(|b| b.header.height).unwrap_or(0),
        end_height: blocks.last().map(|b| b.header.height).unwrap_or(0),
        merkle_root,
        aegis_signature: signature,
        peer_public_key: self.aegis_public_key.clone(),
        timestamp,
        peer_id,
    })
}
```

**Verification**:
```rust
pub async fn verify_signed_block_pack_compressed(
    &self,
    pack: &SignedBlockPack,
) -> Result<Vec<QBlock>> {
    // 1. Verify timestamp
    if !verify_timestamp(pack.timestamp) {
        anyhow::bail!("Invalid timestamp");
    }

    // 2. Verify signature over compressed data
    let mut message = Vec::new();
    message.extend_from_slice(&pack.compressed_blocks);
    message.extend_from_slice(&pack.merkle_root);
    message.extend_from_slice(&pack.timestamp.to_le_bytes());
    message.extend_from_slice(pack.peer_id.as_bytes());

    let aegis = self.aegis.lock().await;
    if !aegis.verify(&message, &pack.aegis_signature, &pack.peer_public_key)? {
        self.peer_trust.record_invalid_signature(&pack.peer_id, pack.peer_public_key.clone());
        anyhow::bail!("Invalid AEGIS-QL signature");
    }

    // 3. Decompress blocks
    let serialized = zstd::bulk::decompress(&pack.compressed_blocks, 10_000_000)?;  // 10MB limit
    let blocks: Vec<QBlock> = postcard::from_bytes(&serialized)?;

    // 4. Verify merkle root matches decompressed blocks
    let block_hashes: Vec<[u8; 32]> = blocks.iter()
        .map(|b| b.calculate_hash())
        .collect();
    let computed_root = compute_merkle_root(&block_hashes);

    if computed_root != pack.merkle_root {
        self.peer_trust.record_merkle_failure(&pack.peer_id, pack.peer_public_key.clone());
        anyhow::bail!("Merkle root mismatch");
    }

    // 5. Record success
    self.peer_trust.record_valid_pack(&pack.peer_id, pack.peer_public_key.clone());

    Ok(blocks)
}
```
