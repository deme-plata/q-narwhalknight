## 🏗️ ARCHITECTURE

### Layer 1: Signed Block Packs

```rust
/// AEGIS-QL signed block pack for P2P transmission
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SignedBlockPack {
    /// Blocks being transmitted (batch of up to 1000)
    pub blocks: Vec<QBlock>,

    /// Merkle root of all block hashes (for integrity)
    pub merkle_root: [u8; 32],

    /// AEGIS-QL post-quantum signature
    pub aegis_signature: q_aegis_ql::Signature,

    /// Sender's AEGIS-QL public key
    pub peer_public_key: q_aegis_ql::PublicKey,

    /// Timestamp (prevents replay attacks)
    pub timestamp: i64,

    /// Peer ID (for P2P routing, not cryptographic)
    pub peer_id: String,
}
```

**Key Features:**
- Batch up to 1000 blocks per pack
- Merkle root provides O(1) integrity verification
- Post-quantum signature ensures authenticity
- Timestamp prevents replay attacks

### Layer 2: Sync Affirmation Certificate

```rust
/// Certificate proving successful sync completion
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct SyncAffirmationCertificate {
    /// Start height of synced range
    pub start_height: u64,

    /// End height of synced range
    pub end_height: u64,

    /// Hash of every block in range (for verification)
    pub block_hashes: Vec<[u8; 32]>,

    /// Merkle root of all block_hashes
    pub merkle_root: [u8; 32],

    /// AEGIS-QL signature over (start, end, merkle_root)
    pub aegis_signature: q_aegis_ql::Signature,

    /// Timestamp
    pub timestamp: i64,

    /// Syncing peer's public key
    pub syncer_public_key: q_aegis_ql::PublicKey,
}
```

**Purpose:**
- Stored in database as proof sync completed
- Prevents restart loops - node knows it already synced
- Can be verified by any peer
- Compact: only stores hashes, not full blocks

### Layer 3: Peer Trust Registry

```rust
/// Track peer reliability based on signature verification
#[derive(Debug, Clone)]
pub struct PeerTrustRegistry {
    /// Map peer_id -> trust metrics
    peers: DashMap<String, PeerTrustMetrics>,
}

#[derive(Debug, Clone)]
pub struct PeerTrustMetrics {
    /// Number of valid signed packs received
    pub valid_packs: u64,

    /// Number of invalid signatures detected
    pub invalid_signatures: u64,

    /// Number of blocks with wrong merkle roots
    pub merkle_failures: u64,

    /// Trust score (0.0 - 1.0)
    pub trust_score: f64,

    /// Last seen timestamp
    pub last_seen: i64,

    /// Peer's AEGIS-QL public key
    pub public_key: q_aegis_ql::PublicKey,
}
```

**Benefits:**
- Automatically ban peers sending invalid signatures
- Prioritize trusted peers for sync
- Track historical reliability

## 📡 P2P PROTOCOL FLOW

### 1. Request Signed Blocks

```
Node A (Syncing):
  └──> Send TurboSyncRequest { start_height, end_height, want_signatures: true }
       via gossipsub topic: /qnk/testnet-phase2/turbo-sync-request

Node B (Serving):
  └──> Receive request
       ├──> Load blocks from storage
       ├──> Compute merkle root
       ├──> Sign with AEGIS-QL secret key
       └──> Send SignedBlockPack via gossipsub
            topic: /qnk/testnet-phase2/turbo-sync-response-signed
```

### 2. Verify Signed Blocks

```
Node A (Syncing):
  └──> Receive SignedBlockPack
       ├──> 1. Verify AEGIS-QL signature
       │    └──> aegis.verify(message, signature, peer_public_key)
       ├──> 2. Verify merkle root
       │    └──> computed_root == pack.merkle_root
       ├──> 3. Verify timestamp (within 5 minutes)
       │    └──> now - pack.timestamp < 300 seconds
       ├──> 4. Store blocks in database
       └──> 5. Update peer trust metrics
```

### 3. Generate Sync Affirmation

```
Node A (Syncing):
  └──> After sync complete
       ├──> Collect all block hashes [start_height..end_height]
       ├──> Compute merkle root of hashes
       ├──> Sign with own AEGIS-QL secret key
       ├──> Store SyncAffirmationCertificate in database
       └──> Log: "✅ [SYNC AFFIRMED] height 0 → 4078 (certificate stored)"
```

### 4. Prevent Restart Loops

```
Node Startup:
  └──> Load latest SyncAffirmationCertificate from database
       ├──> If certificate.end_height >= current_height:
       │    └──> Skip sync (already affirmed)
       ├──> Else if certificate.end_height < current_height - 100:
       │    └──> Resume sync from certificate.end_height
       └──> Else:
            └──> Verify blocks still match certificate hashes
```

## 🔐 SECURITY PROPERTIES

### 1. **Post-Quantum Resistance**
- AEGIS-QL uses sparse Ring-LWE (256-bit classical, 128-bit quantum)
- Signatures remain secure even against Shor's algorithm
- Future-proof: safe for next 30+ years

### 2. **Replay Attack Prevention**
- Timestamps must be within 5-minute window
- Old signed packs automatically rejected
- Protects against malicious peers re-sending old data

### 3. **Merkle Integrity**
- O(1) verification of entire block batch
- Single corrupted block invalidates entire pack
- Prevents selective block tampering

### 4. **Privacy Preservation**
- Signatures don't reveal IP addresses
- Peer IDs are ephemeral (rotated every session)
- No linkability between sessions

### 5. **Sybil Resistance**
- Each valid signed pack increases peer trust
- Invalid signatures result in immediate ban
- Trust scores prevent Sybil attacks

## 📊 PERFORMANCE IMPACT

### Signature Generation (Per Pack):
- **AEGIS-QL Sign**: ~2-3ms (sparse Ring-LWE)
- **Merkle Root**: ~1ms (1000 blocks)
- **Total Overhead**: ~4ms per 1000 blocks

### Signature Verification (Per Pack):
- **AEGIS-QL Verify**: ~3-4ms
- **Merkle Check**: ~1ms
- **Total Overhead**: ~5ms per 1000 blocks

### Network Overhead:
- **Signature**: 2KB (AEGIS-QL sparse polynomial)
- **Public Key**: 1KB
- **Total**: ~3KB per pack

**Analysis:**
- For 10,000 blocks: 10 packs × 5ms = 50ms total
- Sync speed: ~200,000 blocks/second (CPU bound)
- Network: 3KB/pack = 30KB for 10,000 blocks
- **Negligible impact** compared to block download time

## 📝 USAGE EXAMPLE

### Sender (Node B):

```rust
// Load blocks
let blocks = storage.get_qblocks_range(1000, 2000).await?;

// Create signed pack
let pack = turbo_sync.create_signed_block_pack(blocks, &secret_key).await?;

// Send via gossipsub
network.publish_signed_pack(&pack).await?;
```

### Receiver (Node A):

```rust
// Receive pack
let pack: SignedBlockPack = decode_gossipsub_message(msg)?;

// Verify signature
if !turbo_sync.verify_signed_pack(&pack).await? {
    warn!("❌ Invalid signature from peer {}", pack.peer_id);
    peer_trust.ban_peer(&pack.peer_id).await;
    return Err(AegisError::InvalidSignature);
}

// Store blocks
for block in pack.blocks {
    storage.store_qblock(&block).await?;
}

// Update trust
peer_trust.record_valid_pack(&pack.peer_id).await;
```

### Sync Affirmation:

```rust
// After sync complete
let certificate = SyncAffirmationCertificate {
    start_height: 0,
    end_height: 4078,
    block_hashes: compute_all_hashes(0, 4078).await?,
    merkle_root: compute_merkle_root(&block_hashes),
    aegis_signature: aegis.sign(&message, &secret_key)?,
    timestamp: current_timestamp(),
    syncer_public_key: public_key.clone(),
};

// Store certificate
storage.store_sync_certificate(&certificate).await?;
info!("✅ [SYNC AFFIRMED] 0 → 4078 (certificate: {})", hex::encode(&certificate.merkle_root));
```
