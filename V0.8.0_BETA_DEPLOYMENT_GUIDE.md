## 📋 Step-by-Step Deployment

### Phase 1: Pre-Deployment Backup

```bash
# 1. Stop the current service
sudo systemctl stop q-api-server

# 2. Backup current binary
cp /opt/orobit/shared/q-narwhalknight/target/release/q-api-server \
   /opt/orobit/shared/q-narwhalknight/target/release/q-api-server-v0.7.4-beta-backup

# 3. Backup database (CRITICAL)
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
cp -r /opt/orobit/shared/q-narwhalknight/data \
      /opt/orobit/backups/data-pre-v0.8.0-${TIMESTAMP}

# 4. Verify backups
ls -lh /opt/orobit/backups/
ls -lh /opt/orobit/shared/q-narwhalknight/target/release/q-api-server-v0.7.4-beta-backup
```

### Phase 2: Build Verification

```bash
# 1. Wait for build to complete
tail -f /tmp/v0.8.0-beta-build.log
# Press Ctrl+C when you see: "Finished `release` profile"

# 2. Verify binary exists
ls -lh ./target/release/q-api-server

# 3. Check binary info
file ./target/release/q-api-server
# Expected: ELF 64-bit LSB executable, x86-64

# 4. Quick version check (optional)
./target/release/q-api-server --version 2>&1 | head -5
```

### Phase 3: Deployment

```bash
# 1. Copy new binary to production location (already in place from build)
# Binary is at: /opt/orobit/shared/q-narwhalknight/target/release/q-api-server

# 2. Set proper permissions
chmod +x /opt/orobit/shared/q-narwhalknight/target/release/q-api-server

# 3. Start the service
sudo systemctl start q-api-server

# 4. Verify startup
sudo systemctl status q-api-server
```

### Phase 4: Verification & Monitoring


## 🔴 Failure Scenarios & Responses

### Scenario 1: Service Won't Start

**Symptoms**:
- Service fails immediately
- Error in systemctl status

**Response**:
```bash
# 1. Check logs
journalctl -u q-api-server --since "1 minute ago" --no-pager

# 2. Try manual start for detailed error
cd /opt/orobit/shared/q-narwhalknight
./target/release/q-api-server --port 8080

# 3. If binary issue: Rollback
sudo systemctl stop q-api-server
cp target/release/q-api-server-v0.7.4-beta-backup target/release/q-api-server
sudo systemctl start q-api-server
```

### Scenario 2: Balance Consensus Errors

**Symptoms**:
- "CRITICAL: Balance consensus failed" in logs
- Blocks being rejected

**Response**:
```bash
# 1. Capture error logs
journalctl -u q-api-server --since "10 minutes ago" | grep "CRITICAL.*BALANCE" > /tmp/consensus-errors.log

# 2. Check error type
cat /tmp/consensus-errors.log

# 3. If persistent errors: Rollback immediately
sudo systemctl stop q-api-server
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
cp -r data data-failed-v0.8.0-${TIMESTAMP}
cp -r /opt/orobit/backups/data-pre-v0.8.0-* data
cp target/release/q-api-server-v0.7.4-beta-backup target/release/q-api-server
sudo systemctl start q-api-server

# 4. Report issue with logs
cat /tmp/consensus-errors.log
```

### Scenario 3: Performance Degradation

**Symptoms**:
- Slow block processing
- High CPU usage
- Memory issues

**Response**:
```bash
# 1. Check resource usage
top -bn1 | grep q-api-server
free -h
df -h

# 2. Monitor consensus overhead
journalctl -u q-api-server -f | grep "Processed.*balance updates"
# Should show: "Processed N balance updates" in <100ms

# 3. If severe degradation: Consider rollback
# (Balance consensus should have <1ms overhead)
```

## 🔄 Rollback Procedure

### When to Rollback
- **Immediate**: Service won't start, crashes repeatedly
- **Short-term**: Persistent consensus errors (>5% of blocks)
- **Medium-term**: Performance degradation >10%

### Rollback Steps

```bash
# 1. Stop current service
sudo systemctl stop q-api-server

# 2. Restore previous binary
cp /opt/orobit/shared/q-narwhalknight/target/release/q-api-server-v0.7.4-beta-backup \
   /opt/orobit/shared/q-narwhalknight/target/release/q-api-server

# 3. Restore database (if data corruption occurred)
LATEST_BACKUP=$(ls -t /opt/orobit/backups/data-pre-v0.8.0-* | head -1)
rm -rf /opt/orobit/shared/q-narwhalknight/data
cp -r ${LATEST_BACKUP} /opt/orobit/shared/q-narwhalknight/data

# 4. Start service
sudo systemctl start q-api-server

# 5. Verify rollback success
sudo systemctl status q-api-server
journalctl -u q-api-server -f | head -50
```
