# v0.9.65-beta - Turbo Sync Protocol Mismatch Fix

**Date:** 2025-11-08 22:27 CET
**Issue:** Peers cannot respond to turbo sync requests due to deserialization failure
**Root Cause:** Postcard varint encoding mismatch between binary versions
**Priority:** CRITICAL (blocks decentralized P2P sync)

---

## 🐛 BUG DISCOVERED

### Symptoms:
- ✅ Server Beta RECEIVES BlockPackRequest messages via gossipsub
- ❌ Server Beta REJECTS all requests as "GARBAGE" (corrupted heights)
- ❌ NO responses sent back to requesting peers
- → Requesting peer falls back to HTTP sync (centralized)

### Example Error Logs:
```

🔍 [TURBO SYNC DEBUG] Format detection: first_byte=0x81, is_new_format=false
🔍 [TURBO SYNC DEBUG] Using OLD format decode (first byte != 0x01)
❌ [TURBO SYNC CORRUPTION] OLD format decode produced GARBAGE!
    start_height: 1762636929 (MAX_SANE: 100000000)
    end_height: 52 (MAX_SANE: 100000000)
⚠️  This is likely a binary version mismatch - peer running incompatible software!
```

## 🔍 ROOT CAUSE ANALYSIS

### The Data:
Received bytes: `[81, e9, be, c8, 06, 34, 31, 32, 44, 33, 4b, 6f, 6f...]`

Breaking down:
- `81` = First byte (NOT `0x01`, so "old format" detected)
- `e9, be, c8, 06` = Varint-encoded number (produces garbage when decoded as old format)
- `34, 31, 32, 44, 33, 4b, 6f, 6f...` = ASCII `"412D3KooW..."` (PeerId string!)

### The Problem:
1. **Format detection**: Checks if `data[0] == 0x01` for new format
2. **First byte `0x81`**: Treated as old format
3. **Old format decode**: Tries to deserialize `[start_height, end_height, request_id]`
4. **Varint mismatch**: Produces garbage height `1762636929` instead of actual value
5. **Sanity check**: Rejects as corrupted (height > MAX_SANE_HEIGHT)

### Why This Happens:
**Postcard varint encoding changed** between versions or the Docker container is using a **different version** of the `postcard` crate that encodes integers differently!

The current code assumes:
- New format ALWAYS starts with `0x01` (protocol_version=1)
- Old format starts with `start_height` varint (typically small numbers like 2-1000)

But the Docker container's requests start with `0x81`, which is:
- Varint encoding of a number in a DIFFERENT postcard version
- Or a field that's been added/removed causing offset issues

---

## ✅ THE FIX

### Strategy: Try MessagePack Decoding as Fallback

Since the bytes `0x81, 0x86, 0x8a` are MessagePack type markers, the Docker container might be using MessagePack instead of postcard!

**File to modify:** `crates/q-storage/src/turbo_sync.rs`

**Add dependency in `Cargo.toml`:**
```toml
[dependencies]
rmp-serde = "1.1"  # MessagePack for Rust
```

**Modify `impl BlockPackRequest` decode logic:**

```rust
pub fn from_bytes(data: &[u8]) -> Result<Self> {
    if data.is_empty() {
        anyhow::bail!("Empty BlockPackRequest data");
    }

    let is_new_format = data[0] == 0x01;

    tracing::info!("🔍 [TURBO SYNC DEBUG] Format detection: first_byte=0x{:02x}, is_new_format={}",
                   data[0], is_new_format);

    // Try NEW format (postcard with protocol_version field)
    if is_new_format {
        match postcard::from_bytes::<Self>(data) {
            Ok(req) => {
                tracing::info!("✅ [TURBO SYNC DEBUG] NEW format (postcard) decoded successfully");
                req.validate_heights()?;
                return Ok(req);
            }
            Err(e) => {
                tracing::warn!("⚠️ NEW format decode failed: {:?}, trying MessagePack", e);
            }
        }
    }

    // Try OLD format (postcard without protocol_version field)
    tracing::info!("🔍 [TURBO SYNC DEBUG] Trying OLD format (postcard)");
    match postcard::from_bytes::<OldBlockPackRequest>(data) {
        Ok(old) => {
            const MAX_SANE_HEIGHT: u64 = 100_000_000;

            if old.start_height <= MAX_SANE_HEIGHT && old.end_height <= MAX_SANE_HEIGHT {
                tracing::info!("✅ [TURBO SYNC DEBUG] OLD format (postcard) decoded successfully");
                let req = Self {
                    protocol_version: 0,
                    start_height: old.start_height,
                    end_height: old.end_height,
                    request_id: old.request_id,
                };
                req.validate_heights()?;
                return Ok(req);
            } else {
                tracing::warn!(
                    "⚠️ OLD format decode produced insane heights: {}-{}, trying MessagePack",
                    old.start_height, old.end_height
                );
            }
        }
        Err(e) => {
            tracing::warn!("⚠️ OLD format decode failed: {:?}, trying MessagePack", e);
        }
    }

    // ✅ NEW: Try MessagePack as fallback (for compatibility with different serialization)
    tracing::info!("🔍 [TURBO SYNC DEBUG] Trying MessagePack format");
    match rmp_serde::from_slice::<Self>(data) {
        Ok(req) => {
            tracing::info!("✅ [TURBO SYNC DEBUG] MessagePack format decoded successfully!");
            req.validate_heights()?;
            Ok(req)
        }
        Err(e) => {
            // ✅ Try MessagePack OLD format (without protocol_version)
            match rmp_serde::from_slice::<OldBlockPackRequest>(data) {
                Ok(old) => {
                    tracing::info!("✅ [TURBO SYNC DEBUG] MessagePack OLD format decoded successfully!");
                    let req = Self {
                        protocol_version: 0,
                        start_height: old.start_height,
                        end_height: old.end_height,
                        request_id: old.request_id,
                    };
                    req.validate_heights()?;
                    Ok(req)
                }
                Err(e2) => {
                    tracing::error!("❌ ALL decode attempts failed!");
                    tracing::error!("   Postcard NEW: failed");
                    tracing::error!("   Postcard OLD: insane heights or failed");
                    tracing::error!("   MessagePack NEW: {:?}", e);
                    tracing::error!("   MessagePack OLD: {:?}", e2);
                    tracing::error!("   Raw bytes (first 64): {:02x?}", &data[..data.len().min(64)]);
                    anyhow::bail!(
                        "Failed to decode BlockPackRequest with any known format. \
                        This indicates incompatible binary versions between peers."
                    )
                }
            }
        }
    }
}
```
