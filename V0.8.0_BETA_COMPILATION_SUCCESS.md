   ```bash
   timeout 36000 cargo build --release --package q-api-server

   ```

3. **Monitor balance consensus initialization**:
   ```bash
   journalctl -u q-api-server -f | grep -i "balance consensus"
   # Expected: "✅ Balance consensus engine initialized"
   ```

4. **Watch for consensus processing**:

   ```bash
   journalctl -u q-api-server -f | grep -i "BALANCE CONSENSUS"
   ```
