## 💥 HOW IT WAS HAPPENING

### Pruning Configuration (OLD - v0.9.0):
```rust
impl Default for PruningMode {
    fn default() -> Self {
        PruningMode::Adaptive  // THIS WAS DELETING YOUR BLOCKS!
    }
}

impl Default for PruningConfig {
    fn default() -> Self {
        Self {
            mode: PruningMode::Adaptive,
            retain_recent_blocks_days: 30,      // Only keeps last 30 days
            checkpoint_interval: 55_000,        // Checkpoints every 55,000 blocks
            auto_prune_interval: 3600,          // Runs EVERY HOUR!
        }
    }
}
```

### What Happened to Your 3000 Blocks:
```
HOUR 1: You mine blocks 0-3000
- Pruning runs (auto_prune_interval: 3600 = 1 hour)
- Checks each block: should_retain_block(0-3000)?
  - Block 0: KEEP (genesis)
  - Block 1-2999: DELETE (not checkpoints, adaptive policy)
  - Block 3000: KEEP (current tip)
- Result: 2999 blocks DELETED!

HOUR 2: You continue mining
- Pruning runs again
- More blocks deleted
- Height keeps dropping

Eventually: Only genesis + current tip remain
```

### The Retention Logic:
```rust
fn adaptive_retention_policy(&self, block_height: u64, current_height: u64) -> Result<bool> {
    // Always retain recent blocks and checkpoints
    if self.is_recent_block(block_height, current_height) || self.is_checkpoint_block(block_height) {
        return Ok(true);   // KEEP
    }

    // Normal adaptive policy - THIS RETURNS FALSE FOR OLD BLOCKS!
    Ok(self.is_checkpoint_block(block_height) || self.is_recent_block(block_height, current_height))
}

fn is_checkpoint_block(&self, block_height: u64) -> bool {
    block_height == 0 || block_height % 55_000 == 0  // Only every 55,000 blocks!
}
```

**Translation**: Unless your block is:
- Genesis (block 0), OR
- A checkpoint (every 55,000 blocks), OR
- "Recent" (within last 30 days of mining at 6.67s/block)

It gets DELETED.
