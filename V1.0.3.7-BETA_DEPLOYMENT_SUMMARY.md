### Fix #1: Sync Loop Iteration Counter ✅
**Location**: `crates/q-api-server/src/main.rs:5717-5728`

**Purpose**: Detect if sync loop stops executing (state machine poisoning detection)

**Implementation**:
```rust
static SYNC_LOOP_ITERATIONS: AtomicU64 = AtomicU64::new(0);

loop {
    interval.tick().await;

    let iteration = SYNC_LOOP_ITERATIONS.fetch_add(1, Ordering::SeqCst);
    if iteration % 100 == 0 {
        info!("🔁 [SYNC LOOP] iteration={} (loop is executing)", iteration);
    }
    ...
}
```

**Expected Output** (every 10 seconds):
```
🔁 [SYNC LOOP] iteration=100 (loop is executing)
🔁 [SYNC LOOP] iteration=200 (loop is executing)
🔁 [SYNC LOOP] iteration=300 (loop is executing)
```

**Diagnostic Value**:
- **Counter increases**: Sync loop is executing normally ✅
- **Counter stops**: Sync loop died (state machine poisoning) ❌
- **Rate limiting**: Only logs every 100 iterations (10 seconds)

### Fix #2: Non-Blocking Height Check (Sleep-Drop Fix) ✅
**Location**: `crates/q-api-server/src/main.rs:6234-6271`

**Purpose**: Eliminate 10-second blocking delay before batch sync evaluation

**Old Code (BLOCKING)**:
```rust
tokio::time::sleep(std::time::Duration::from_secs(10)).await;

let height_after_fast_sync = app_state_sync.node_status.read().await.current_height;
if height_after_fast_sync > current_height {
    info!("✅ [FAST SYNC] Received blocks!");
    continue;
} else {
    warn!("⚠️ [FAST SYNC] Timeout");
}
```

**Problem**: Blocks for full 10 seconds even if P2P fails immediately, delaying batch sync activation.

**New Code (NON-BLOCKING)**:
```rust
let wait_start = tokio::time::Instant::now();
let height_check_timeout = wait_start + std::time::Duration::from_secs(10);
let mut height_check_interval = tokio::time::interval(std::time::Duration::from_millis(100));

let mut height_advanced = false;
while tokio::time::Instant::now() < height_check_timeout {
    height_check_interval.tick().await;

    let new_height = app_state_sync.node_status.read().await.current_height;
    if new_height > initial_height {
        info!("✅ [FAST SYNC] Received {} blocks!", new_height - initial_height);
        info!("⚡ [FAST SYNC] Early exit after {:.1}s", elapsed);
        height_advanced = true;
        break;  // Exit early!
    }
}

if !height_advanced {
    warn!("⚠️ [FAST SYNC] Timeout - no blocks received in 10s");
    info!("🔄 [FAST SYNC] Proceeding to batch sync evaluation...");
}

if height_advanced {
    continue;  // Skip batch sync
}

// Fall through to batch sync evaluation
```

**Benefits**:
1. **Early Exit**: If P2P succeeds in 1s, we continue immediately (saves 9s)
2. **Guaranteed Evaluation**: Always reaches batch sync code path
3. **Better Diagnostics**: Logs exact wait time and performance
4. **Responsive**: Checks every 100ms instead of blocking

**Expected Output** (P2P success):
```
✅ [FAST SYNC] Received 512 blocks! (height: 1 → 513)
⚡ [FAST SYNC] Early exit after 1.2s (target was 10s) - 25600 blocks/min
```

**Expected Output** (P2P failure → batch sync):
```
⚠️  [FAST SYNC] Timeout - no blocks received in 10s
🔄 [FAST SYNC] Proceeding to batch sync evaluation...
🚨 [BATCH SYNC CRITICAL] Entering batch sync branch (gap=7201 blocks)
```
