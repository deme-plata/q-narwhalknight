## ✅ THE FIX (v0.9.19-beta)

### Fix Location

**File**: `crates/q-storage/src/turbo_sync.rs`
**Function**: `sync_to_height()` (line ~1044)

### Implementation Plan

**Step 1**: Register response channels BEFORE sending requests

```rust
// Create response channel for each chunk
let (response_tx, response_rx) = oneshot::channel();
let request_id = generate_request_id();

// Register in response map (shared with main.rs gossipsub handler)
response_map.lock().await.insert(request_id.clone(), response_tx);

// Send request
send_block_pack_request(request_id, start_height, end_height).await?;
```

**Step 2**: Wait for responses with timeout

```rust
// Wait for response (max 30 seconds)
match timeout(Duration::from_secs(30), response_rx).await {
    Ok(Ok(pack)) => {
        info!("✅ [TURBO SYNC] Received pack for blocks {}-{}",
              pack.start_height, pack.end_height);

        // Apply pack to storage
        apply_block_pack(pack).await?;
    }
    Ok(Err(e)) => {
        anyhow::bail!("Pack response error: {}", e);
    }
    Err(_) => {
        anyhow::bail!("Timeout waiting for block pack response");
    }
}
```

**Step 3**: Validate blocks written before returning

```rust
// Verify blocks actually written to storage
let new_height = self.get_latest_qblock_height().await?;
if new_height.unwrap_or(0) < target_height {
    anyhow::bail!(
        "TURBO SYNC INCOMPLETE: Target {}, got {}",
        target_height, new_height.unwrap_or(0)
    );
}

// Only return Ok() if ALL blocks written
Ok(())
```

### Response Map Integration

TurboSync just needs to use it!
