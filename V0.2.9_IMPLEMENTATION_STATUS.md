**Dashboard.tsx** - Listen for custom event and update wallet balances:
```typescript
// Lines 1282-1310: Listen for real-time balance updates
useEffect(() => {
  const handleWalletBalanceUpdate = (event: Event) => {
    const customEvent = event as CustomEvent;
    const { symbol, balance, reason } = customEvent.detail;

    console.log(`💰 Dashboard: Received wallet-balance-updated event for ${symbol}:`, balance, 'Reason:', reason);

    // Update the specific wallet in the walletBalances array
    setWalletBalances(prev => {
      const updated = prev.map(wallet => {
        if (wallet.symbol === symbol) {
          console.log(`✅ Dashboard: Updating ${symbol} balance from ${wallet.balance} to ${balance}`);
          return { ...wallet, balance };
        }
        return wallet;
      });
      return updated;
    });
  };

  window.addEventListener('wallet-balance-updated', handleWalletBalanceUpdate);
  console.log('👂 Dashboard: Listening for wallet-balance-updated events');

  return () => {
    window.removeEventListener('wallet-balance-updated', handleWalletBalanceUpdate);
    console.log('🔇 Dashboard: Stopped listening for wallet-balance-updated events');
  };
}, []);
```

**How It Works**:
1. Backend emits SSE `balance-updated` event when balance changes (mining, transactions, etc.)
2. App.tsx SSE handler receives event and updates TopBar balance
3. App.tsx dispatches custom `wallet-balance-updated` event
4. Dashboard listens for event and updates specific wallet in `walletBalances` array
5. User sees real-time balance update with smooth animation (via AnimatedBalance component)

export const applyForLoan = async (
  borrowerAddress: string,
  loanAmount: number, // QUGUSD
  collateralAmount: number, // QUG
  termMonths: number
) => {
  const response = await authenticatedFetch('/api/bank/lending/apply', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      borrower_address: borrowerAddress,
      loan_amount: (loanAmount * 100_000_000).toString(), // Convert to base units
      collateral_amount: (collateralAmount * 100_000_000).toString(),
      term_months: termMonths,
    }),
  });

  return response.json();
};
```

const handleSubmit = async () => {

## 📊 Banking System Architecture (Summary)

### Existing Infrastructure:
- **CDP Minting**: `mint_qnkusd()` at quillon_bank_api.rs:246-418
- **Collateral Locking**: Deducts from wallet balance (lines 379-405)
- **Balance Updates**: Emits SSE events (App.tsx:291-299)
- **Real-time UI**: Dashboard listens and updates (Dashboard.tsx:1282-1310)

### New Loan System (To Be Implemented):
- **Loan Application**: `POST /api/bank/lending/apply`
- **Loan Storage**: Database with loan records (loan_id, terms, status)
- **Interest Calculation**: Dynamic based on credit, collateral, term
- **Repayment Tracking**: Monthly payments, remaining balance
- **Liquidation**: Auto-trigger at 120% collateral ratio

### Data Flow:
```
User clicks "Apply for Loan" button
  ↓
LoanApplicationModal opens
  ↓
User enters loan amount, selects term
  ↓
Frontend calculates required collateral (150% ratio)
  ↓
Frontend calculates estimated interest rate
  ↓
User clicks "Submit"
  ↓
Frontend calls `/api/bank/lending/apply`
  ↓
Backend validates wallet has sufficient QUG
  ↓
Backend locks QUG collateral (deduct from wallet_balances)
  ↓
Backend mints QUGUSD (add to token_balances)
  ↓
Backend creates loan record in database
  ↓
Backend emits SSE `balance-updated` event
  ↓
App.tsx receives SSE event, dispatches `wallet-balance-updated`
  ↓
Dashboard.tsx updates wallet balances in real-time
  ↓
User sees updated balances instantly
  ↓
