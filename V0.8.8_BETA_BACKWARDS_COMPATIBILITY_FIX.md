## 🔧 The Solution

### Backwards Compatible Deserialization

**Added**: `BlockPackRequest::from_bytes()` method in `crates/q-storage/src/turbo_sync.rs`

**How It Works**:
1. Try to deserialize with new format (with `protocol_version` field)
2. If corruption detected (impossible heights), try old format
3. If new format fails entirely, fallback to old format
4. Old format has no `protocol_version` field, just heights

**Code Added** (`crates/q-storage/src/turbo_sync.rs:153-202`):
```rust
/// ✅ v0.8.8-beta: Backwards compatible deserialization
pub fn from_bytes(data: &[u8]) -> Result<Self> {
    // Try new format first (with protocol_version field)
    match postcard::from_bytes::<Self>(data) {
        Ok(req) => {
            // Validate that heights make sense (corruption detection)
            if let Err(e) = req.detect_corruption() {
                // If corruption detected, try old format as fallback
                warn!("New format failed corruption check: {}, trying old format", e);
                Self::try_old_format(data)
            } else {
                Ok(req)
            }
        }
        Err(_) => {
            // New format failed, try old format
            Self::try_old_format(data)
        }
    }
}

fn try_old_format(data: &[u8]) -> Result<Self> {
    #[derive(serde::Deserialize)]
    struct OldBlockPackRequest {
        pub start_height: u64,
        pub end_height: u64,
        pub request_id: String,
    }

    let old = postcard::from_bytes::<OldBlockPackRequest>(data)?;

    info!(
        "✅ [TURBO SYNC COMPAT] Decoded old-format request: blocks {}-{} (ID: {})",
        old.start_height,
        old.end_height,
        &old.request_id[..old.request_id.len().min(16)]
    );

    Ok(Self {
        protocol_version: 0, // Mark as old format
        start_height: old.start_height,
        end_height: old.end_height,
        request_id: old.request_id,
    })
}
```
