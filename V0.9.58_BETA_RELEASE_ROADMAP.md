# v0.9.57-beta Release Roadmap

## Overview

Building on v0.9.56-beta's enhanced diagnostics, v0.9.57-beta will focus on **protocol version negotiation**, **binary version verification**, and **automatic compatibility handling**.

## 🎯 Priority 1: Protocol Version Negotiation

### Problem
Currently, nodes with different binary versions can communicate but fail silently with deserialization errors. There's no handshake to verify compatibility.

### Solution: P2P Protocol Handshake

**Implementation in `crates/q-network/src/unified_network_manager.rs`:**

```rust
#[derive(Serialize, Deserialize, Debug, Clone)]
pub struct ProtocolHandshake {
    /// Binary version (e.g., "v0.9.56-beta")
    pub binary_version: String,

    /// Turbo sync protocol version (1 = NEW format with protocol_version field)
    pub turbo_sync_version: u32,

    /// Supported turbo sync versions for backwards compatibility
    pub supported_turbo_sync_versions: Vec<u32>,

    /// Compilation timestamp (to detect stale binaries)
    pub build_timestamp: u64,

    /// Network ID (must match for communication)
    pub network_id: String,

    /// Feature flags (for capability negotiation)
    pub features: Vec<String>,
}

impl ProtocolHandshake {
    pub fn current() -> Self {
        Self {
            binary_version: env!("CARGO_PKG_VERSION").to_string(),
            turbo_sync_version: 1, // NEW format
            supported_turbo_sync_versions: vec![0, 1], // Support both OLD and NEW
            build_timestamp: BUILD_TIMESTAMP, // Set at compile time
            network_id: "testnet-phase5".to_string(),
            features: vec![
                "turbo-sync".to_string(),
                "balance-consensus".to_string(),
                "distributed-ai".to_string(),
            ],
        }
    }

    pub fn is_compatible(&self, peer: &ProtocolHandshake) -> Result<bool> {
        // Network ID must match
        if self.network_id != peer.network_id {
            anyhow::bail!("Network ID mismatch: {} vs {}", self.network_id, peer.network_id);
        }

        // Find common turbo sync version
        let common_versions: Vec<_> = self.supported_turbo_sync_versions
            .iter()
            .filter(|v| peer.supported_turbo_sync_versions.contains(v))
            .collect();

        if common_versions.is_empty() {
            anyhow::bail!("No compatible turbo sync protocol versions");
        }

        Ok(true)
    }

    pub fn negotiate_turbo_sync_version(&self, peer: &ProtocolHandshake) -> u32 {
        // Always prefer highest common version
        let common_versions: Vec<_> = self.supported_turbo_sync_versions
            .iter()
            .filter(|v| peer.supported_turbo_sync_versions.contains(v))
            .copied()
            .collect();

        *common_versions.iter().max().unwrap_or(&0)
    }
}
```

**Handshake on Peer Connection:**

```rust
// When a peer connects, exchange handshakes
pub async fn on_peer_connected(&mut self, peer_id: PeerId) -> Result<()> {
    let our_handshake = ProtocolHandshake::current();

    // Send our handshake
    self.send_handshake_to_peer(peer_id, &our_handshake).await?;

    // Wait for peer's handshake (with 5s timeout)
    match timeout(Duration::from_secs(5), self.receive_handshake_from_peer(peer_id)).await {
        Ok(Ok(peer_handshake)) => {
            if let Err(e) = our_handshake.is_compatible(&peer_handshake) {
                error!("❌ Peer {} incompatible: {}", peer_id, e);
                error!("   Our version: {}, Their version: {}",
                       our_handshake.binary_version, peer_handshake.binary_version);

                // Disconnect incompatible peer
                self.disconnect_peer(peer_id).await?;
                return Ok(());
            }

            let negotiated_version = our_handshake.negotiate_turbo_sync_version(&peer_handshake);

            info!("✅ Peer {} compatible:", peer_id);
            info!("   Our version: {}", our_handshake.binary_version);
            info!("   Their version: {}", peer_handshake.binary_version);
            info!("   Negotiated turbo sync version: {}", negotiated_version);

            // Store negotiated version for this peer
            self.peer_turbo_sync_versions.insert(peer_id, negotiated_version);

            Ok(())
        }
        Ok(Err(e)) => {
            error!("❌ Failed to receive handshake from peer {}: {}", peer_id, e);
            self.disconnect_peer(peer_id).await?;
            Ok(())
        }
        Err(_) => {
            error!("❌ Handshake timeout with peer {}", peer_id);
            self.disconnect_peer(peer_id).await?;
            Ok(())
        }
    }
}
```

**Benefits:**
- ✅ Automatic version detection
- ✅ Graceful degradation to common protocol version
- ✅ Clear error messages when incompatible
- ✅ Prevents silent deserialization failures

## 🎯 Priority 2: Build Timestamp Verification

### Problem
Docker containers can have stale binaries with misleading version tags (e.g., `q-api-v0.9.57-altest-beta` running v0.9.52 binary).

### Solution: Compile-Time Build Timestamp

**Implementation in `build.rs` (workspace root):**

```rust
// build.rs
use std::time::{SystemTime, UNIX_EPOCH};

fn main() {
    let build_time = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .unwrap()
        .as_secs();

    println!("cargo:rustc-env=BUILD_TIMESTAMP={}", build_time);

    // Also set a human-readable timestamp
    let now = chrono::Utc::now();
    println!("cargo:rustc-env=BUILD_DATE={}", now.format("%Y-%m-%d %H:%M:%S UTC"));
}
```

**Add to `Cargo.toml`:**

```toml
[workspace.dependencies]
chrono = "0.4"

[package]
build = "build.rs"
```

## 🎯 Priority 3: Per-Peer Protocol Version Tracking

### Problem
Currently, BlockPackRequest uses a global format. If peers have different versions, we need to send the correct format to each peer.

### Solution: Dynamic Serialization Based on Peer Version

**Implementation in `crates/q-storage/src/turbo_sync.rs`:**

```rust
impl BlockPackRequest {
    /// Serialize for a specific peer based on their negotiated protocol version
    pub fn to_bytes_for_peer(&self, peer_version: u32) -> Result<Vec<u8>> {
        match peer_version {
            0 => {
                // OLD format: [start_height, end_height, request_id]
                #[derive(Serialize)]
                struct OldFormat {
                    start_height: u64,
                    end_height: u64,
                    request_id: String,
                }

                let old = OldFormat {
                    start_height: self.start_height,
                    end_height: self.end_height,
                    request_id: self.request_id.clone(),
                };

                postcard::to_allocvec(&old)
                    .context("Failed to serialize OLD format BlockPackRequest")
            }
            1 => {
                // NEW format: [protocol_version, start_height, end_height, request_id]
                postcard::to_allocvec(self)
                    .context("Failed to serialize NEW format BlockPackRequest")
            }
            _ => {
                anyhow::bail!("Unsupported peer turbo sync version: {}", peer_version);
            }
        }
    }
}
```

**Updated sender in `crates/q-api-server/src/main.rs`:**

```rust
// Get negotiated version for this peer (from handshake)
let peer_version = network_manager
    .get_peer_turbo_sync_version(&peer_id)
    .unwrap_or(1); // Default to NEW format

// Serialize using peer's version
let data = pack_request.to_bytes_for_peer(peer_version)?;

info!("📤 [TURBO SYNC DEBUG] Sending BlockPackRequest to peer {} (version {}):",
      peer_id, peer_version);
info!("   Protocol Version: {}", pack_request.protocol_version);
info!("   Heights: {}-{}", start_height, end_height);
info!("   Request ID: {}", &request_id[..16]);
info!("   Serialized bytes (len={}): {:02x?}", data.len(), &data[..data.len().min(64)]);
```

**Benefits:**
- ✅ Backwards compatibility with old nodes
- ✅ Automatic format selection per peer
- ✅ Smooth upgrades (no hard cutover)
- ✅ Heterogeneous network support

## 🎯 Priority 4: Automated Binary Verification on Startup

### Problem
Services can restart with old binaries without anyone noticing until failures occur.

### Solution: Startup Self-Check

**Implementation in `crates/q-api-server/src/main.rs`:**

```rust
async fn verify_binary_version() -> Result<()> {
    let version = env!("CARGO_PKG_VERSION");
    let build_date = env!("BUILD_DATE");
    let build_timestamp: u64 = env!("BUILD_TIMESTAMP").parse()?;

    info!("🔍 Binary Version Verification:");
    info!("   Version: {}", version);
    info!("   Build Date: {}", build_date);
    info!("   Build Timestamp: {}", build_timestamp);

    // Check if binary is older than 30 days
    let now = SystemTime::now().duration_since(UNIX_EPOCH)?.as_secs();
    let age_days = (now - build_timestamp) / 86400;

    if age_days > 30 {
        warn!("⚠️  WARNING: Binary is {} days old!", age_days);
        warn!("⚠️  Consider updating to the latest version");
    }

    // Check expected version based on deployment (optional)
    if let Ok(expected_version) = std::env::var("Q_EXPECTED_VERSION") {
        if version != expected_version {
            error!("❌ CRITICAL: Binary version mismatch!");
            error!("   Expected: {}", expected_version);
            error!("   Actual: {}", version);
            error!("   This may indicate a stale binary in Docker container");

            // Optionally refuse to start
            if std::env::var("Q_STRICT_VERSION_CHECK").is_ok() {
                anyhow::bail!("Version mismatch - refusing to start");
            }
        } else {
            info!("✅ Binary version matches expected: {}", version);
        }
    }

    Ok(())
}

#[tokio::main]
async fn main() -> Result<()> {
    // Verify binary version FIRST
    verify_binary_version().await?;

    // Continue with normal startup...
}
```

**Docker Usage:**

```bash
docker run -d \
  --name q-api-v0.9.56-beta \
  -e Q_EXPECTED_VERSION="0.9.56-beta" \
  -e Q_STRICT_VERSION_CHECK=1 \
  q-api:v0.9.56-beta
```

**Benefits:**
- ✅ Catches stale Docker containers immediately
- ✅ Warns about old binaries
- ✅ Optional strict mode refuses to start
- ✅ Clear diagnostic messages

## 🎯 Priority 5: Enhanced Gossipsub Message Deduplication

### Problem
Server Alpha was receiving its own OLD format requests back via gossipsub echo.

### Solution: Message Origin Tracking

**Implementation in `crates/q-network/src/unified_network_manager.rs`:**

```rust
use std::collections::HashSet;
use std::sync::Arc;
use parking_lot::RwLock;

pub struct MessageDeduplicator {
    /// Recently sent message IDs (prevent processing our own messages)
    sent_messages: Arc<RwLock<HashSet<String>>>,

    /// Recently received message IDs (prevent duplicate processing)
    received_messages: Arc<RwLock<HashSet<String>>>,
}

impl MessageDeduplicator {
    pub fn new() -> Self {
        let deduplicator = Self {
            sent_messages: Arc::new(RwLock::new(HashSet::new())),
            received_messages: Arc::new(RwLock::new(HashSet::new())),
        };

        // Clean up old entries every 60 seconds
        let sent_clone = deduplicator.sent_messages.clone();
        let received_clone = deduplicator.received_messages.clone();
        tokio::spawn(async move {
            let mut interval = tokio::time::interval(Duration::from_secs(60));
            loop {
                interval.tick().await;
                sent_clone.write().clear();
                received_clone.write().clear();
            }
        });

        deduplicator
    }

    pub fn mark_sent(&self, message_id: &str) {
        self.sent_messages.write().insert(message_id.to_string());
    }

    pub fn is_our_message(&self, message_id: &str) -> bool {
        self.sent_messages.read().contains(message_id)
    }

    pub fn mark_received(&self, message_id: &str) -> bool {
        // Returns true if this is a NEW message (not seen before)
        self.received_messages.write().insert(message_id.to_string())
    }
}
```

**Usage in message handler:**

```rust
// When sending a BlockPackRequest
deduplicator.mark_sent(&request_id);

// When receiving a BlockPackRequest
if deduplicator.is_our_message(&request.request_id) {
    debug!("🔁 Ignoring our own BlockPackRequest echo: {}", request.request_id);
    return Ok(());
}

if !deduplicator.mark_received(&request.request_id) {
    debug!("🔁 Ignoring duplicate BlockPackRequest: {}", request.request_id);
    return Ok(());
}
```

**Benefits:**
- ✅ Prevents processing own messages
- ✅ Prevents duplicate processing
- ✅ Automatic cleanup (memory bounded)
- ✅ Thread-safe

## 🎯 Priority 6: Metrics and Monitoring

### Problem
No visibility into protocol version distribution, handshake failures, or compatibility issues across the network.

### Solution: Prometheus Metrics

**Implementation in `crates/q-api-server/src/main.rs`:**

```rust
use prometheus::{IntCounterVec, IntGaugeVec, HistogramVec, register_int_counter_vec, register_int_gauge_vec, register_histogram_vec};

lazy_static! {
    static ref PEER_PROTOCOL_VERSIONS: IntGaugeVec = register_int_gauge_vec!(
        "qnk_peer_protocol_versions",
        "Turbo sync protocol versions of connected peers",
        &["peer_id", "version"]
    ).unwrap();

    static ref HANDSHAKE_FAILURES: IntCounterVec = register_int_counter_vec!(
        "qnk_handshake_failures_total",
        "Failed protocol handshakes",
        &["reason"]
    ).unwrap();

    static ref MESSAGE_FORMAT_MISMATCHES: IntCounterVec = register_int_counter_vec!(
        "qnk_message_format_mismatches_total",
        "Messages received in wrong format",
        &["expected_version", "detected_version"]
    ).unwrap();

    static ref BINARY_AGE_DAYS: IntGaugeVec = register_int_gauge_vec!(
        "qnk_binary_age_days",
        "Age of running binary in days",
        &["version"]
    ).unwrap();
}

// Update metrics
PEER_PROTOCOL_VERSIONS.with_label_values(&[&peer_id.to_string(), &version.to_string()]).set(1);
HANDSHAKE_FAILURES.with_label_values(&["incompatible_network"]).inc();
MESSAGE_FORMAT_MISMATCHES.with_label_values(&["1", "0"]).inc();
BINARY_AGE_DAYS.with_label_values(&[env!("CARGO_PKG_VERSION")]).set(age_days as i64);
```

**Benefits:**
- ✅ Real-time visibility into network compatibility
