## Changes Deployed

### Critical Bug Fix: Balance Flash to Zero
Fixed the issue where balance would flash to `0.000099` instead of showing the correct total balance when receiving mining rewards.

### Root Cause
The backend was sending **the mining reward amount** (e.g., 0.000099 QUG) as `new_balance` in SSE events instead of the **wallet's total balance** (e.g., 93.56 QUG).

### Bugs Fixed

1. **Wrong Unit Multiplier**: Changed from `1e9` to `1e8` (4 locations in main.rs)
2. **SSE Sending Reward Instead of Balance**: Now fetches actual wallet balance from storage (2 locations)
3. **Hardcoded Zero old_balance**: Now calculates actual previous balance
4. **Frontend Animation Flash**: Fixed opacity to prevent visual glitching
