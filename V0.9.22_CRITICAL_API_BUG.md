## 🐛 THE ROOT CAUSE

**File**: `crates/q-api-server/src/handlers.rs` (status endpoint)

**Problem**: The status endpoint is returning `null` values for `current_height` and `peer_id`.

**Possible Causes**:
1. `node_status.read().await.current_height` is returning None/null
2. Peer ID not being set in node status
3. JSON serialization issue with Option<T> types
4. Race condition during initialization
